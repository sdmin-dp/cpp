# T1 小 Z 的手套（gloves）

## 题目意思

有一些左手手套和右手手套，每只手套都有一个尺码。

一只左手手套和一只右手手套配成一副后，它们尺码差的绝对值就是这副手套的丑陋程度。

例如：

```text
左手尺码：5
右手尺码：7
丑陋程度：|5 - 7| = 2
```

小 Z 想配出尽可能多的手套。

在配出最多手套的前提下，还希望最大的尺码差尽可能小。

## 解题思路

先把左右手套的尺码分别从小到大排序。

我们可以猜一个答案 `x`，表示：

> 每一副手套的尺码差都不能超过 `x`。

然后检查这个 `x` 是否可行。

对于一只左手手套 `l[i]`，可以和它配对的右手手套必须满足：

```text
l[i] - x <= r[j] <= l[i] + x
```

我们用两个指针从小到大进行匹配：

- 如果当前右手手套太小，就跳过它；
- 如果当前右手手套可以和左手手套配对，就把它们配成一副；
- 如果当前右手手套已经太大，说明当前左手手套无法匹配。

为什么选择最小的可用右手手套？

因为这样可以把更大的右手手套留给后面尺码更大的左手手套，不会影响答案。

## 为什么可以二分？

如果最大允许差值为 `x` 时可以配出最多的手套，那么允许差值变成 `x + 1` 后，肯定也可以配出来。

所以答案具有单调性：

```text
小于答案：无法配出最多手套
大于等于答案：可以配出最多手套
```

因此可以使用二分答案。

## 复杂度

排序复杂度：

```text
O((n + m) log(n + m))
```

每次检查复杂度：

```text
O(n + m)
```

总复杂度：

```text
O((n + m) log(n + m) + (n + m) log V)
```

其中 `V` 是尺码差的最大值。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

int main() {
    freopen("gloves.in", "r", stdin);
    freopen("gloves.out", "w", stdout);

    int n, m;
    cin >> n >> m;

    vector<ll> left(n), right(m);

    for (ll &x : left) cin >> x;
    for (ll &x : right) cin >> x;

    if (n > m) {
        swap(n, m);
        swap(left, right);
    }

    sort(left.begin(), left.end());
    sort(right.begin(), right.end());

    auto check = [&](ll limit) {
        int j = 0;

        for (int i = 0; i < n; ++i) {
            while (j < m && right[j] < left[i] - limit) {
                ++j;
            }

            if (j == m || right[j] > left[i] + limit) {
                return false;
            }

            ++j;
        }

        return true;
    };

    ll l = 0;
    ll r = max(left.back(), right.back())
         - min(left.front(), right.front());

    while (l < r) {
        ll mid = (l + r) / 2;

        if (check(mid)) {
            r = mid;
        } else {
            l = mid + 1;
        }
    }

    cout << l << '\n';

    return 0;
}
```

# T2 小 Z 的字符串（string）

## 题目意思

字符串只包含 `0`、`1`、`2` 三种字符。

如果字符串中没有两个相邻且相同的字符，就叫作优雅字符串。

例如：

```text
01202
```

是优雅字符串。

而：

```text
00122
```

不是优雅字符串，因为有相邻的 `0` 和相邻的 `2`。

每次操作可以交换相邻的两个字符。

求把原字符串变成优雅字符串最少需要多少次操作。

如果无论如何都无法变成优雅字符串，输出 `-1`。

## 判断是否无解

如果某一种字符太多，就不可能把它们分开。

长度为 `n` 的字符串中，同一种字符最多只能出现：

```text
(n + 1) / 2
```

次。

例如长度为 `5` 时，一种字符最多出现 `3` 次：

```text
0 其他 0 其他 0
```

如果某个字符出现了 `4` 次，就一定无解。

## 关键观察

相同字符之间的相对顺序不会改变。

例如原字符串中三个 `0` 的顺序是：

```text
第一个 0、第二个 0、第三个 0
```

无论怎么交换，它们最后仍然会按照这个顺序出现。

所以我们可以从左到右决定最终字符串每个位置放什么字符。

## 动态规划

定义：

```text
dp[i][j][c]
```

表示：

- 已经放好了 `i` 个 `0`；
- 已经放好了 `j` 个 `1`；
- 最后放的是字符 `c`；
- 当前最少需要移动多少步。

已经放好的 `2` 的数量可以直接算出：

```text
已经放好的 2 的数量 = 当前长度 - i - j
```

放当前字符时，不能和上一个字符相同。

例如当前要放 `0`，那么上一个字符只能是 `1` 或 `2`。

## 如何计算移动代价？

假如原字符串中第 `i` 个 `0` 在位置 `pos`，现在要把它放到位置 `p`。

它需要移动：

```text
abs(pos - p)
```

这么多格。

所有字符的移动距离加起来后，要除以 `2`。

因为一次相邻交换会同时让两个字符各移动一格。

例如：

```text
12 -> 21
```

两个字符一共移动了两格，但实际上只交换了一次。

## 复杂度

时间复杂度：

```text
O(n^2)
```

空间复杂度：

```text
O(n^2)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int MAXN = 405;

int pos[3][MAXN];
int cnt[3];
int dp[MAXN][MAXN][3];

int main() {
    freopen("string.in", "r", stdin);
    freopen("string.out", "w", stdout);

    string s;
    cin >> s;

    int n = s.size();

    for (int i = 0; i < n; ++i) {
        int x = s[i] - '0';
        pos[x][++cnt[x]] = i + 1;
    }

    for (int c = 0; c < 3; ++c) {
        if (cnt[c] > (n + 1) / 2) {
            cout << -1 << '\n';
            return 0;
        }
    }

    for (int i = 0; i <= cnt[0]; ++i) {
        for (int j = 0; j <= cnt[1]; ++j) {
            for (int c = 0; c < 3; ++c) {
                dp[i][j][c] = INF;
            }
        }
    }

    dp[0][0][0] = 0;
    dp[0][0][1] = 0;
    dp[0][0][2] = 0;

    for (int i = 0; i <= cnt[0]; ++i) {
        for (int j = 0; j <= cnt[1]; ++j) {
            int used = i + j;
            int used2 = used - i;

            if (i > 0) {
                int p = used;
                int cost = abs(pos[0][i] - p);

                dp[i][j][0] = min(
                    dp[i - 1][j][1],
                    dp[i - 1][j][2]
                ) + cost;
            }

            if (j > 0) {
                int p = used;
                int cost = abs(pos[1][j] - p);

                dp[i][j][1] = min(
                    dp[i][j - 1][0],
                    dp[i][j - 1][2]
                ) + cost;
            }

            if (used2 > 0 && used2 <= cnt[2]) {
                int p = used;
                int cost = abs(pos[2][used2] - p);

                dp[i][j][2] = min(
                    dp[i][j - 1][0],
                    dp[i][j - 1][1]
                ) + cost;
            }
        }
    }

    int answer = min({
        dp[cnt[0]][cnt[1]][0],
        dp[cnt[0]][cnt[1]][1],
        dp[cnt[0]][cnt[1]][2]
    });

    cout << answer / 2 << '\n';

    return 0;
}
```

# T3 一个真实的故事（truth）

## 题目意思

有一个长度为 `n` 的数组，数组中的数字范围是 `1` 到 `k`。

需要处理很多次操作：

```text
1 p v
```

表示把第 `p` 个数改成 `v`。

```text
2
```

表示询问：

> 数组中最短的连续区间，使得这个区间里出现了所有 `1` 到 `k`。

例如：

```text
数组：2 3 1 2
k = 3
```

区间：

```text
2 3 1
```

里面包含 `1、2、3`，长度为 `3`。

所以答案是：

```text
3
```

如果不存在这样的区间，就输出：

```text
-1
```

## 解题思路

如果每次询问都暴力枚举所有区间，速度会很慢。

所以使用线段树维护答案。

## 每个线段树节点保存什么？

对于一个区间，保存以下信息：

1. 这个区间内部的最短合法区间长度；
2. 每个数字最左边出现的位置；
3. 每个数字最右边出现的位置。

例如区间：

```text
2 3 1 2
```

其中：

```text
数字 1 最左位置：3
数字 2 最左位置：1
数字 2 最右位置：4
数字 3 最左位置：2
```

## 合并两个区间

假设一个大区间由左区间和右区间组成。

最短合法区间只有三种情况：

1. 完全在左区间；
2. 完全在右区间；
3. 一部分在左区间，一部分在右区间。

前两种情况直接使用左右儿子已经算好的答案。

第三种情况需要重新计算。

对于跨过中点的区间：

- 左区间里的数字，取它们最靠右的位置；
- 右区间里的数字，取它们最靠左的位置。

然后把这些位置放在一起，寻找包含所有数字的最短区间。

因为只有 `2 * k` 个位置，所以可以排序后使用双指针。

## 修改操作

修改一个位置时，只会影响这个位置到根节点的路径。

所以在线段树上做单点修改，然后重新计算路径上的节点即可。

## 复杂度

如果合并时排序，单次合并复杂度为：

```text
O(k log k)
```

单次修改复杂度约为：

```text
O(k log k log n)
```

如果使用有序合并，可以把合并优化到：

```text
O(k)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 50005;
const int MAXK = 35;
const int INF = 1e9;

struct Node {
    int l, r;
    int ans;
    int leftPos[MAXK];
    int rightPos[MAXK];
    int value;

    Node() {
        l = r = 0;
        ans = INF;
        value = 0;

        for (int i = 0; i < MAXK; ++i) {
            leftPos[i] = 0;
            rightPos[i] = 0;
        }
    }
};

Node tree[MAXN * 4];

int a[MAXN];
int n, k, m;

void pushUp(int p) {
    Node &cur = tree[p];
    Node &L = tree[p << 1];
    Node &R = tree[p << 1 | 1];

    cur.ans = min(L.ans, R.ans);

    vector<pair<int, int>> points;

    for (int x = 1; x <= k; ++x) {
        if (L.rightPos[x]) {
            points.push_back({L.rightPos[x], x});
        }
    }

    for (int x = 1; x <= k; ++x) {
        if (R.leftPos[x]) {
            points.push_back({R.leftPos[x], x});
        }
    }

    sort(points.begin(), points.end());

    int count[MAXK] = {};
    int have = 0;
    int right = 0;

    for (int left = 0; left < (int)points.size(); ++left) {
        while (right < (int)points.size() && have < k) {
            int number = points[right].second;

            if (count[number] == 0) {
                ++have;
            }

            ++count[number];
            ++right;
        }

        if (have == k) {
            cur.ans = min(
                cur.ans,
                points[right - 1].first - points[left].first + 1
            );
        }

        int number = points[left].second;

        --count[number];

        if (count[number] == 0) {
            --have;
        }
    }

    for (int x = 1; x <= k; ++x) {
        if (L.leftPos[x]) {
            cur.leftPos[x] = L.leftPos[x];
        } else {
            cur.leftPos[x] = R.leftPos[x];
        }

        if (R.rightPos[x]) {
            cur.rightPos[x] = R.rightPos[x];
        } else {
            cur.rightPos[x] = L.rightPos[x];
        }
    }
}

void build(int p, int l, int r) {
    tree[p].l = l;
    tree[p].r = r;

    if (l == r) {
        tree[p].leftPos[a[l]] = l;
        tree[p].rightPos[a[l]] = l;
        tree[p].value = a[l];
        return;
    }

    int mid = (l + r) / 2;

    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);

    pushUp(p);
}

void update(int p, int index, int value) {
    if (tree[p].l == tree[p].r) {
        for (int x = 1; x <= k; ++x) {
            tree[p].leftPos[x] = 0;
            tree[p].rightPos[x] = 0;
        }

        tree[p].leftPos[value] = index;
        tree[p].rightPos[value] = index;
        tree[p].value = value;

        return;
    }

    int mid = (tree[p].l + tree[p].r) / 2;

    if (index <= mid) {
        update(p << 1, index, value);
    } else {
        update(p << 1 | 1, index, value);
    }

    pushUp(p);
}

int main() {
    freopen("truth.in", "r", stdin);
    freopen("truth.out", "w", stdout);

    cin >> n >> k >> m;

    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    build(1, 1, n);

    while (m--) {
        int op;
        cin >> op;

        if (op == 1) {
            int p, v;
            cin >> p >> v;
            update(1, p, v);
        } else {
            if (tree[1].ans == INF) {
                cout << -1 << '\n';
            } else {
                cout << tree[1].ans << '\n';
            }
        }
    }

    return 0;
}
```

# T4 异或区间（xor）

## 题目意思

给定一个数组，需要统计有多少个连续区间满足：

```text
区间所有数的异或和 <= 区间最大值
```

例如区间：

```text
1 2 4
```

异或和为：

```text
1 ^ 2 ^ 4 = 7
```

最大值为：

```text
4
```

因为：

```text
7 <= 4
```

不成立，所以这个区间不符合要求。

## 前缀异或

定义：

```text
s[i] = a[1] ^ a[2] ^ ... ^ a[i]
```

那么区间 `[l, r]` 的异或和就是：

```text
s[r] ^ s[l - 1]
```

这样就可以把一个区间的异或和转换成两个前缀异或值的异或。

## 01 字典树

如果区间最大值固定为 `k`，问题就变成：

```text
统计有多少对前缀异或值 x、y 满足 x ^ y <= k
```

这个问题可以使用 01 字典树。

01 字典树就是按照二进制位来存数字的树。

从最高位到最低位进行比较：

- 如果 `k` 当前位是 `0`，只能继续走相同的分支；
- 如果 `k` 当前位是 `1`，可以统计一部分答案，再继续走另一条分支。

每次查询的复杂度为：

```text
O(log A)
```

其中 `A` 是数字的最大值范围。

## 区间最大值不同怎么办？

原题中每个区间的最大值不一样。

可以找到数组中的最大值 `a[i]`。

所有跨过位置 `i` 的区间，都可以把 `a[i]` 作为最大值来处理。

然后分别处理：

- `i` 左边的区间；
- `i` 右边的区间；
- 跨过 `i` 的区间。

这个过程可以用笛卡尔树完成。

## 笛卡尔树

笛卡尔树有两个特点：

1. 中序遍历后仍然是原数组顺序；
2. 父节点的值大于子节点的值。

因此，每个节点都可以看作一段区间中的最大值。

在笛卡尔树上进行深度优先搜索，就可以递归处理每个区间。

## 启发式合并

处理一个节点时，需要合并左右两边的前缀异或值。

如果每次都把大集合复制到小集合，速度会很慢。

所以采用“小集合合并到大集合”：

1. 找到较短的一边；
2. 枚举较短一边的每个前缀异或值；
3. 到较长一边的字典树中查询；
4. 再把较短一边的数据插入较长一边。

这样每个元素被重复处理的次数较少。

## 复杂度

建笛卡尔树：

```text
O(n)
```

每次字典树操作：

```text
O(log A)
```

总复杂度约为：

```text
O(n log n log A)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

const int MAXN = 100005;
const int MAXBIT = 30;

int a[MAXN];
int prefixXor[MAXN];

int leftChild[MAXN];
int rightChild[MAXN];
int stackArray[MAXN];

int n;
int topIndex;

ll answer = 0;

struct TrieNode {
    int son[2];
    int count;

    TrieNode() {
        son[0] = son[1] = 0;
        count = 0;
    }
};

struct Trie {
    vector<TrieNode> tree;

    Trie() {
        tree.emplace_back();
    }

    void insert(int x) {
        int u = 0;

        for (int bit = MAXBIT; bit >= 0; --bit) {
            int value = (x >> bit) & 1;

            if (!tree[u].son[value]) {
                tree[u].son[value] = tree.size();
                tree.emplace_back();
            }

            u = tree[u].son[value];
            ++tree[u].count;
        }
    }

    ll query(int x, int limit) {
        ll result = 0;
        int u = 0;

        for (int bit = MAXBIT; bit >= 0; --bit) {
            if (!u) {
                return result;
            }

            int xb = (x >> bit) & 1;
            int kb = (limit >> bit) & 1;

            if (kb == 1) {
                int same = tree[u].son[xb];

                if (same) {
                    result += tree[same].count;
                }

                u = tree[u].son[xb ^ 1];
            } else {
                u = tree[u].son[xb];
            }
        }

        if (u) {
            result += tree[u].count;
        }

        return result;
    }
};

Trie dfs(int root, int left, int right) {
    if (left > right) {
        return Trie();
    }

    if (left == right) {
        Trie result;
        result.insert(prefixXor[left]);
        return result;
    }

    Trie leftTrie = dfs(leftChild[root], left, root - 1);
    Trie rightTrie = dfs(rightChild[root], root + 1, right);

    int leftLength = root - left;
    int rightLength = right - root;

    if (leftLength <= rightLength) {
        for (int i = left; i < root; ++i) {
            answer += rightTrie.query(prefixXor[i], a[root]);
        }

        for (int i = left; i < root; ++i) {
            rightTrie.insert(prefixXor[i]);
        }

        rightTrie.insert(prefixXor[root]);

        return rightTrie;
    } else {
        for (int i = root; i <= right; ++i) {
            answer += leftTrie.query(prefixXor[i], a[root]);
        }

        for (int i = root; i <= right; ++i) {
            leftTrie.insert(prefixXor[i]);
        }

        return leftTrie;
    }
}

int main() {
    freopen("xor.in", "r", stdin);
    freopen("xor.out", "w", stdout);

    cin >> n;

    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        prefixXor[i] = prefixXor[i - 1] ^ a[i];
    }

    int root = 0;

    for (int i = 1; i <= n; ++i) {
        int last = 0;

        while (topIndex &&
               a[stackArray[topIndex]] <= a[i]) {
            last = stackArray[topIndex--];
        }

        if (topIndex) {
            rightChild[stackArray[topIndex]] = i;
        }

        leftChild[i] = last;

        stackArray[++topIndex] = i;
    }

    root = stackArray[1];

    dfs(root, 0, n);

    cout << answer << '\n';

    return 0;
}
```

## 复习重点

### T1

看到“最大值最小”，并且判断具有单调性时，可以考虑二分答案。

### T2

如果操作是交换，且相同元素之间的相对顺序不会改变，可以考虑计算每个元素最终移动了多少距离。

### T3

如果数组支持单点修改，同时要维护整个数组的区间答案，可以考虑线段树。

### T4

遇到区间异或，可以先考虑前缀异或。

遇到：

```text
x ^ y <= k
```

可以考虑 01 字典树。
