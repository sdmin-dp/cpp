01 · 整体认识

数据结构：把“数据关系”组织清楚

数据结构不只是容器名称，而是三件事的组合：数据之间有什么关系、允许进行哪些操作、这些操作需要多少时间和空间。

总记忆点：先看关系，再选结构；先看操作，再估复杂度。
结构核心关系最典型操作第一判断
栈后进先出压入、弹出、查看栈顶是否只处理最新加入的数据
队列先进先出入队、出队、查看队首是否按到达顺序处理
树一对多、层次关系遍历、统计子树、向下递归是否存在父子层级

合法出栈序列与卡特兰数

固定入栈顺序为 1,2,3,...,n，允许在过程中随时出栈。不同合法出栈序列的数量不是 n!，而是第 n 个卡特兰数：

Cn = C(2n,n)/(n+1)组合数公式
Cn = Σ CiCn−1−i0 ≤ i < n
1, 1, 2, 5, 14, 42...C0 到 C5

3 个元素依次入栈时，共有 5 种合法出栈序列：

出栈序列一种对应操作关键时刻
1 2 3入1出1，入2出2，入3出3每入一个立即出
1 3 2入1出1，入2，入3，出3出22 等在栈底
2 1 3入1入2，出2出1，入3出3先处理前两个
2 3 1入1入2出2，入3出3出11 一直留在栈底
3 2 1全部入栈，再全部出栈完全逆序
为什么 3 1 2 不合法：为了先弹出 3，必须先把 1、2、3 全部压栈；弹出 3 后，栈顶是 2，不可能越过 2 先弹出 1。
long long f[30];
f[0] = 1;
for (int n = 1; n <= 20; n++) {
	for (int i = 0; i < n; i++) {
		f[n] += f[i] * f[n - 1 - i];
	}
}

转换的关键不是死记扫描规则，而是先用括号确定运算树，再把每个运算符移动到两个操作对象的前面或后面。

运算符处理规则

  1. 操作数直接输出。
  2. 左括号直接入栈。
  3. 右括号让运算符出栈，直到遇到左括号。
  4. 普通运算符先弹出优先级更高或相等的栈顶，再入栈。
  5. 扫描结束，把剩余运算符全部弹出。

后缀表达式求值

遇到数字

把数字压入数值栈。

遇到运算符

先弹出右操作数，再弹出左操作数。

完成运算

把计算结果重新压入栈，最后栈中只剩答案。

顺序不能反：计算减法和除法时，第二次弹出的数在左边，即 a op b。

统一理解法：括号三步走

以 A+B*(C-D) 为例。先根据优先级补全括号，得到唯一的运算层次：

(A + (B * (C − D)))

中缀 → 前缀

第 1 步：补全括号(A + (B * (C − D)))
第 2 步：运算符移到括号前(+ A (* B (− C D)))
第 3 步：删除括号+ A * B − C D

中缀 → 后缀

第 1 步：补全括号(A + (B * (C − D)))
第 2 步：运算符移到括号后(A (B (C D −) *) +)
第 3 步：删除括号A B C D − * +

前缀 → 中缀

从右向左扫描 − * A B / C D，操作数入栈；遇到运算符，弹出两个表达式并组合为 (左 运算符 右)。

扫描符号组合动作表达式栈（栈顶在左）
D、C、/(C/D)(C/D)
B、A、*(A*B)(A*B), (C/D)
−((A*B)−(C/D))只剩完整表达式
去括号保留优先级必需的结构A*B−C/D

后缀 → 中缀

从左向右扫描 A B * C D / −。遇到运算符时，先弹出的是右表达式，后弹出的是左表达式。

扫描符号弹栈与组合表达式栈
A、B、*右=B，左=A，组成 (A*B)(A*B)
C、D、/右=D，左=C，组成 (C/D)(A*B), (C/D)
−右=(C/D)，左=(A*B)((A*B)−(C/D))
去括号依据优先级删除多余括号A*B−C/D
四类转换统一记忆：中缀先补括号再移动运算符；前缀从右向左合并；后缀从左向右合并。

核心代码：中缀转后缀（单字符操作数）

int pri(char c) {
	if (c == '+' || c == '-') return 1;
	if (c == '*' || c == '/' || c == '%') return 2;
	return 0;
}

string to_postfix(string s) {
	stack<char> st;
	string ans;
	for (char c : s) {
		if (isalnum(c)) ans += c;
		else if (c == '(') st.push(c);
		else if (c == ')') {
			while (st.top() != '(') ans += st.top(), st.pop();
			st.pop();
		} else {
			while (!st.empty() && pri(st.top()) >= pri(c)) {
				ans += st.top();
				st.pop();
			}
			st.push(c);
		}
	}
	while (!st.empty()) ans += st.top(), st.pop();
	return ans;
}

核心代码：后缀转中缀

stack<string> st;
for (char c : s) {

	else {
		string b = st.top(); st.pop();  // 先弹出右边
		string a = st.top(); st.pop();
		st.push("(" + a + c + b + ")");
	}
}

名称指向变化时机

rear下一个可插入位置入队后向后移动

典型应用

// 读取并出队

}

// 当前长度
int len = rear - front;

循环队列：让下标绕回开头

把数组首尾想象成相连的圆环，指针每次移动后对容量取模，就能重复利用已经空出的空间。

循环队列实验

容量 6

本课件采用的约定

front 指向队首元素，rear 指向下一个空位。为了区分“空”和“满”，始终空出一个位置。

front == rear队列为空
(rear+1)%N == front队列已满
(rear-front+N)%N当前元素个数

指针移动

操作先做什么再移动
入队a[rear]=xrear=(rear+1)%N
出队读取或删除 a[front]front=(front+1)%N
易错点：不同教材对 rear 的定义可能不同。写题前先固定约定，空、满、长度公式必须与约定配套。

核心代码：保留一个空位的循环队列

const int M = 100;
int q[M];
int front = 0, rear = 0;

bool empty() { return front == rear; }
bool full() { return (rear + 1) % M == front; }

// 入队 x
if (!full()) {
	q[rear] = x;
	rear = (rear + 1) % M;
}

// 出队
if (!empty()) {
	int x = q[front];
	front = (front + 1) % M;
}

06 · 层次结构

树的基础：父子关系与子树

树是一种没有环的连通结构。除根节点外，每个节点恰好有一个父节点；一个节点可以有多个孩子。

概念在图中的例子
根A，没有父节点
父子A 是 B 的父，B 是 A 的孩子
兄弟B、C、D 拥有同一父节点
节点的度A 的度为 3，C 的度为 0
叶子C、E、F、G、H，度为 0
深度若根深度为 1，则 E 深度为 3
高度从节点向下到最深叶子的最长层数
森林删除根 A 后，剩余三棵子树
深度向上数，高度向下数：深度描述节点离根多远，高度描述节点下面还能走多深。题目若把根深度定义为 0，所有深度会整体少 1。

树的三个基本事实

边数 = n − 1n 个节点的树
任意两点路径唯一不会出现两条不同简单路径
连通且无环二者共同刻画树

核心代码：邻接表存树与 DFS

vector<int> g[N];
int dep[N], siz[N];

void dfs(int u, int fa) {
	siz[u] = 1;
	for (int v : g[u]) {
		if (v == fa) continue;     // 不沿原边返回父节点
		dep[v] = dep[u] + 1;
		dfs(v, u);
		siz[u] += siz[v];          // 汇总孩子子树大小
	}
}

07 · 特殊的树

二叉树：每个节点至多两个孩子

二叉树区分左孩子和右孩子。只有一个孩子时，也必须说明它是左孩子还是右孩子。

严格二叉树

每个非叶节点恰好有两个孩子。英文常称 full binary tree。

满二叉树

每一层都放满，高度为 h 时节点数是 2^h−1。

完全二叉树

除最后一层外都放满，最后一层从左到右连续排列。

斜树

每个节点几乎只有一个孩子，形状退化成链。n 个节点的高度可能达到 n。

二叉搜索树：提前认识

通常满足“左子树较小、右子树较大”。它强调大小关系；堆只强调父子关系，二者不能混淆。

术语提醒：中文竞赛语境中的“满二叉树”通常指每层全满；部分英文资料把“每个节点有 0 或 2 个孩子”称为 full binary tree。阅读题目时以题目定义为准。

左子树 i 个节点，右子树 n−1−i 个节点，因此 Bn = Σ BiBn−1−i。

遍历序列能否唯一还原二叉树

已知序列能否唯一还原关键原因
前序 + 中序能前序先找根，中序划分左右子树
后序 + 中序能后序最后找根，中序划分左右子树
层序 + 中序通常能层序确定每个区间最先出现的根
前序 + 后序一般不能只有一个孩子时，无法判断是左还是右
只有一种序列不能许多不同树可产生相同序列

方法一：前序 + 中序还原

前序第一个是根。在中序中找到根，根左边一定属于左子树，右边一定属于右子树；再按节点数量切分前序。

① 找总根

前：A B D E C F G

中：D B E | A | F C G

② 分别找子树根

左前：B D E　右前：C F G

③ 递归完成

D | B | E　　F | C | G

方法二：后序 + 中序还原

后序最后一个是根。中序仍负责划分左右子树；后序中先出现左子树，再出现右子树，最后才是根。

① 找总根

后：D E B F G C | A

中：D B E | A | F C G

② 切分后序

左后：D E B

右后：F G C

③ 继续取各段末尾

D E | B　　F G | C

方法三：层序 + 中序还原

当前层序中第一个属于该中序区间的节点就是根。中序分段后，把剩余层序按“属于左段还是右段”过滤，保持原相对顺序。

① 层序首项是根

层：A B C D E F G

中：D B E | A | F C G

② 过滤左右层序

左层：B D E

右层：C F G

③ 对子区间继续过滤

B→D,E　　C→F,G

为什么 n0 = n2 + 1

设叶子节点、一孩节点、二孩节点数量分别为 n0、n1、n2。

从节点总数看边数

总节点数 n = n0 + n1 + n2，树的边数为 n−1。

从孩子数量看边数

每个孩子对应一条父子边，所以边数 = n1 + 2n2。

令两种边数相等：n0 + n1 + n2 − 1 = n1 + 2n2，整理得到 n0 = n2 + 1。

完全二叉树的数组编号

采用 1 下标公式存在条件
父节点i / 2i > 1
左孩子2 * i2*i <= n
右孩子2 * i + 12*i+1 <= n
节点所在层floor(log2(i)) + 1根为第 1 层
n 个节点的高度floor(log2(n)) + 1n > 0

把层数和节点数放到同一张图中

等比数列求和：错位相减

原式

S = 1 + 2 + 2² + ... + 2h−1

每一层是上一层的 2 倍。

整体乘 2，向后错一位

2S = 2 + 2² + ... + 2h−1 + 2h

中间各项会在相减时全部抵消。

2S − S = 2h − 1，所以 S = 2h − 1。

推广到 m 叉树

如果每个节点至多有 m 个孩子，第 k 层至多有 mk−1 个节点。高度 h 的满 m 叉树：

S=1+m+...+mh−1层节点数形成等比数列
mS−S=mh−1错位相减
S=(mh−1)/(m−1)m > 1

例如满三叉树高度为 4，最多节点数为 (3⁴−1)/(3−1)=40。

10 · 网络结构

图论基础：点、边、方向与连通

图由顶点集合 V 和边集合 E 组成。树是特殊的图；图可以有环、可以不连通，也可以具有方向和权值。

无向图

边没有方向，A—B 与 B—A 是同一条边。所有顶点度数之和等于 2|E|。

有向图

边有起点和终点。进入节点的是入边，离开节点的是出边；所有入度之和与出度之和都等于 |E|。

图的核心概念

概念含义判断重点
路径沿边从一个点走到另一个点的顶点序列有向图必须顺着箭头
简单路径除必要情况外不重复经过顶点不要重复点
环起点和终点相同的封闭路径DAG 是无环有向图
连通无向图任意两点之间都有路径不连通图可拆成多个连通块
强连通有向图任意两点都能互相到达u→v 和 v→u 都要存在路径
弱连通忽略方向后连通只说明底层无向结构连通
权边或点附带距离、费用、时间等数值路径长度常为边权之和

路径、环与连通：看图判断

路径 A→B→C→D
环 A→B→C→A
连通图：只有一个连通块
不连通图：两个连通块
判断顺序：先确定边是否有方向，再按方向检查路径；出现回到起点的封闭路径才构成环；无向图任意两点可达才叫连通。

连通块

完全图的边数

无向完全图中，每对不同顶点之间恰有一条边：

m = n(n−1)/2

不含自环的有向完全图中，每个有序点对都有一条边：

m = n(n−1)

三种常见存图方式

方式空间查一条边遍历邻点适用
邻接矩阵O(n²)O(1)O(n)点少、边密

核心代码：邻接表与连通块

vector<int> g[N];
bool vis[N];

// 无向边：两个方向都要加入
g[u].push_back(v);
g[v].push_back(u);

void dfs(int u) {
	vis[u] = true;
	for (int v : g[u]) {
		if (!vis[v]) dfs(v);
	}
}

int cnt = 0;
for (int i = 1; i <= n; i++) {
	if (!vis[i]) {
		cnt++;                    // 新发现一个连通块
		dfs(i);
	}
}

11 · 优先结构

堆：反复取得当前最值

堆是一棵完全二叉树，并满足父子之间的大小关系。小根堆的父节点不大于孩子，大根堆则相反。

记忆点：堆只保证“父子有序”，不保证整棵树从左到右有序。

小根堆实验

交互

核心操作

操作过程复杂度
读取堆顶直接读取根节点O(1)
插入放到数组末尾，再向上调整O(log n)
删除堆顶末尾补到根，再向下调整O(log n)
建堆从最后一个非叶节点向下调整O(n)

向上与向下调整

  • 向上：新节点与父节点比较，违反堆序就交换。
  • 向下：父节点与两个孩子中更优者比较，违反堆序就交换。
  • 完全二叉树高度是 O(log n)，所以一次调整也是 O(log n)。
堆不是二叉搜索树：小根堆只能确定根最小，不能确定某个值在左子树还是右子树。

核心代码：STL 小根堆

priority_queue<int, vector<int>, greater<int>> q;

q.push(x);                   // 插入，内部自动向上调整
int mn = q.top();            // 读取最小值
q.pop();                     // 删除最小值，内部自动向下调整

bool is_empty = q.empty();
int len = q.size();

void up(int x) {
	while (x > 1 && h[x] < h[x / 2]) {

	}

对顶堆：动态维护中位数

把所有数从中间分成两半：较小的一半放入大根堆，较大的一半放入小根堆。两个堆顶正好隔着中间分界线，因此可以随时得到中位数。

记忆点：左边用大根堆，取“较小一半中的最大值”；右边用小根堆，取“较大一半中的最小值”。两个堆顶面对面。

插入一个数的步骤

  1. 若左堆为空，或 x ≤ left.top()，把 x 放入左堆；否则放入右堆。
  2. 若左堆比右堆多 2 个，把左堆顶移动到右堆。
  3. 若右堆比左堆多 1 个，把右堆顶移动到左堆。
  4. 奇数个元素时中位数是左堆顶；偶数个元素时按题意取下中位数、上中位数或两者平均值。

核心代码：插入与查询中位数

priority_queue<int> left_heap;  // 大根堆：保存较小的一半
priority_queue<int, vector<int>, greater<int>> right_heap; // 小根堆

void add(int x) {
	if (left_heap.empty() || x <= left_heap.top()) {
		left_heap.push(x);
	} else {
		right_heap.push(x);
	}

	// 约定：左堆数量等于右堆，或恰好多 1 个
	if (left_heap.size() > right_heap.size() + 1) {
		right_heap.push(left_heap.top());
		left_heap.pop();
	}
	if (right_heap.size() > left_heap.size()) {
		left_heap.push(right_heap.top());
		right_heap.pop();
	}
}

int lower_mid() {             // 奇偶均返回下中位数
	return left_heap.top();
}

double average_mid() {        // 偶数个数时返回两个中位数的平均值
	if (left_heap.size() > right_heap.size()) return left_heap.top();
	return (1.0 * left_heap.top() + right_heap.top()) / 2;
}
易错点：题目中的“中位数”口径必须先确认。偶数个数时，下中位数是左堆顶，上中位数是右堆顶，统计学中位数才是两者平均值。若还要删除任意旧元素，通常需要使用哈希表记录“延迟删除”，不能直接在堆中查找删除。
