01 · 计数语言

组合数学：不枚举，也能数清所有方案

组合数学研究“有多少种”。真正的难点不是套公式，而是判断对象是否有序、能否重复、是否相同、能否为空，以及限制条件会不会造成重复或遗漏。

总记忆点：先把一个方案描述清楚，再决定它是“分类相加”“分步相乘”，还是需要去重、补集、容斥或递推。
第一问

是否有顺序

选出甲乙丙与安排甲乙丙的先后次序不是同一个问题。

第二问

是否可重复

选过的对象能否再次选择，会直接改变每一步的选择数。

第三问

对象是否相同

相同球交换位置不会产生新方案，不同球交换位置会。

第四问

限制是什么

相邻、不相邻、至少、至多、固定位置与不能回原位对应不同方法。

题目特征优先方法核心动作
互斥类别加法原理各类方案数相加
连续步骤乘法原理每一步选择数相乘
必须相邻 / 不能相邻捆绑 / 插空先压成整体 / 先造空隙
至少一个、不全满足正难则反总数减去反面
多个限制发生重叠容斥原理加单项、减交集、再补高阶交集
无法直接写公式递推或组合DP按最后一步、最后一个对象划分

    09 · 反面与重叠

    正难则反与容斥原理

    “至少一个”往往包含大量重叠情况。若反面只有“一个都没有”，先算全集再减反面通常更稳定；若多个集合重叠，则需要容斥修正重复。

    两个集合的动态容斥

    修改人数观察区域
    |A∪B|=|A|+|B|−|A∩B|交集被加了两次，减回一次
    至少一个=总数−一个都没有正难则反
    恰好满足=至少满足−满足更多分层剥离

    三个集合为什么要“加减加”

    |A∪B∪C| = |A|+|B|+|C|

    　　　　　 −|A∩B|−|A∩C|−|B∩C|

    　　　　　 +|A∩B∩C|

    三重交集先被单集合加 3 次，又被两两交集减 3 次，最后必须再加 1 次。

    容斥处理隔板上界

    求 x1+⋯+xk=n 且 0≤xi≤b。先算无上界方案，再减去至少一个 xi≥b+1 的方案；两个变量同时超界的部分被多减，要加回来。

    错排递推

    设 Dn 表示 n 个对象全部不在原位置的排列数。观察 1 号去到位置 k：

    若 k 号回到位置 1，则 1 与 k 互换，剩余 n−2 个对象错排：Dn−2。

    若 k 号不去位置 1，可把位置 1 看成 k 号的新禁位，剩余形成 n−1 个对象的错排：Dn−1。

    k 有 n−1 种选择，因此 Dn=(n−1)(Dn−1+Dn−2)。

    D1=0，D2=1递推边界
    Dn=(n−1)(Dn−1+Dn−2)交换或继续错排
    Dn=n!Σ(−1)k/k!容斥形式

dp[0] = 1;

	int i = __builtin_popcount(mask);       // 正在安排第 i 个人
	for (int j = 0; j < n; j++) {
		if ((mask >> j & 1) == 0 && ok[i][j]) {
			dp[mask | (1 << j)] += dp[mask];
		}
	}
}

    网格路径：把走法看成 R、U 的排列

    从左下走到右上，如果只能向右和向上，那么每条路径都对应一个由 R 与 U 组成的字符串。

    亲自走一条路径

    右移 R，上移 U

    从 (0,0) 到 (a,b) 必须走 a 次 R 和 b 次 U，共 a+b 步。

    只要在 a+b 个位置中选出 b 个位置放 U，其余自动是 R。

    路径数 = Ca+bb = Ca+ba。

    必须经过某点 P

    起点到 P 的方案数，乘以 P 到终点的方案数。

    不能经过某点 P

    总路径数减去“经过 P”的路径数。

    多个障碍

    障碍较少可排序后容斥；一般网格直接使用路径DP。

    合法括号路径

    “(”上升，“)”下降

    从全部路径减去越界路径

    第一次跌到边界下方后，把此前路径关于边界反射，可与 C2nn+1 条坏路径一一对应。

    Cn=C2nn−C2nn+1=C2nn/(n+1)。

    05 · 排列技巧

    捆绑法、插空法与定序法

    这三种方法都在改变“计数单位”：捆绑把多个对象看成一个整体，插空先制造合法位置，定序则删除内部顺序造成的重复。

    捆绑法：必须相邻

    把 A、B 捆成一个整体

    整体外排，内部再排

    例：A、B、C、D 排队，要求 A、B 相邻。

    把 [AB] 看成一个对象，与 C、D 一起排列：3! 种。

    捆内可以是 AB 或 BA：2! 种。因此共有 3!×2!=12 种。

    插空法：不能相邻

    点击空隙，依次放入 X、Y

    每个空隙最多放一个

    先排列普通对象 A、B、C、D，共 4! 种。

    它们制造出 5 个空隙：_ A _ B _ C _ D _。

    把 X、Y 放入不同空隙且区分顺序：A52 种。因此共有 4!·A52 种。

    定序法：只保留一种相对顺序

    A、B、C 的相对顺序实验

    六种内部顺序取一种
    定序记忆点：如果一个无序选择在总排列中被 k! 种内部顺序重复表示，而题目只允许其中一种，就除以 k!。
    限制先做什么再做什么
    若干对象必须相邻捆成一个整体参与外部排列乘上捆内排列数
    若干对象互不相邻先排普通对象制造空隙从空隙中选位置或排列特殊对象
    若干对象相对顺序固定先不管限制计算全部顺序除去内部 k! 种等价顺序

    02 · 计数起点

    加法原理与乘法原理

    加法解决“任选一类就完成”，乘法解决“所有步骤都完成才算一个完整方案”。

    计数路线实验

    调整数字观察结构

    加法原理

    完成任务有若干个互不重叠的类别，第 i 类有 ni 种：

    n1+n2+⋯+nk任选一类即可完成

    乘法原理

    完成任务必须依次完成若干步，第 i 步有 ni 种：

    n1×n2×⋯×nk每一步都必须完成
    判断关键：“或”通常相加，“且、然后、每一步”通常相乘，但必须先确认分类是否重叠。类别重叠时不能直接相加。

    03 · 基础公式

    排列数 A 与组合数 C

    排列关注“选谁并按什么顺序”，组合只关注“选了谁”。先有组合，再把选出的 m 个对象排序，就得到排列。

    Anm=n!/(n-m)!从 n 个不同对象中有序取 m 个
    Cnm=n!/[m!(n-m)!]从 n 个不同对象中无序取 m 个
    Anm=Cnm·m!先选，再排

    第一位有 n 种，第二位有 n−1 种，……，第 m 位有 n−m+1 种。

    Anm = n(n−1)⋯(n−m+1) = n!/(n−m)!

    同一组 m 个对象会因为内部的 m! 种顺序被排列重复计算，因此 Cnm = Anm/m!。

	long long ans = 1;
	for (int i = 0; i < m; i++) ans *= n - i;

long long C(int n, int m) {
	if (m < 0 || m > n) return 0;
	m = min(m, n - m);          // 利用对称性减少乘法次数
	long long ans = 1;
	for (int i = 1; i <= m; i++) {
		ans = ans * (n - m + i) / i;
	}
	return ans;
}

    组合DP：按最后一个对象分类

    当限制条件破坏了简单公式时，仍可沿用组合恒等式的思想：对于当前对象，要么不选，要么选。

    可点击的杨辉三角

    点击任意 C(n,m)

    设 dp[i][j] 表示前 i 个对象中恰好选择 j 个的方案数。

    不选第 i 个：dp[i−1][j]。

    选择第 i 个：先从前 i−1 个中选 j−1 个，即 dp[i−1][j−1]。

    dp[i][j]=dp[i−1][j]+dp[i−1][j−1]，这正是组合数递推。

    二维写法

    dp[0][0] = 1;
for (int i = 1; i <= n; i++) {
	dp[i][0] = 1;
	for (int j = 1; j <= i; j++) {
		dp[i][j] = dp[i - 1][j] + dp[i - 1][j - 1];
	}
}

    一维滚动

    dp[0] = 1;
for (int i = 1; i <= n; i++) {
	for (int j = min(i, m); j >= 1; j--) {
		dp[j] += dp[j - 1];
	}
}
    为什么倒序：若 j 从小到大更新，dp[j-1]可能已经使用过当前对象，会让同一个对象在一轮中被重复选择。

    组合DP可以增加什么状态

    选择数量

    dp[i][j]：前 i 个选 j 个。

    选择总和

    dp[j][s]：选 j 个且总和为 s。

    限制状态

    增加奇偶、余数、相邻关系、颜色数量等维度。

    组合数计算与模型拓展

    数学模型确定后，还要根据 n、模数和查询次数选择计算方法。直接阶乘只适合范围很小且不取模的情况。

    场景方法复杂度注意
    n 较小，批量求所有 C杨辉三角O(n²)不需要除法，模数任意
    模质数，多次查询阶乘 + 逆阶乘预处理 O(n)，查询 O(1)使用费马逆元
    n 很大，模质数 p 较小Lucas 定理O(logpn)按 p 进制逐位计算
    结果要求精确且很大质因数指数或高精度依实现而定避免中间阶乘溢出
    模数不是质数质因数分解、扩展Lucas较高不能随意使用费马逆元

    模质数下的阶乘与逆阶乘

    const int MOD = 1000000007;
long long fac[N], invfac[N];

long long qpow(long long a, long long b) {
	long long ans = 1;
	while (b) {
		if (b & 1) ans = ans * a % MOD;
		a = a * a % MOD;
		b >>= 1;
	}
	return ans;
}

void pre() {
	fac[0] = 1;
	for (int i = 1; i < N; i++) fac[i] = fac[i - 1] * i % MOD;
	invfac[N - 1] = qpow(fac[N - 1], MOD - 2);
	for (int i = N - 1; i; i--) invfac[i - 1] = invfac[i] * i % MOD;
}

long long C(int n, int m) {
	if (m < 0 || m > n) return 0;
	return fac[n] * invfac[m] % MOD * invfac[n - m] % MOD;
}
