冒泡排序

每一轮从左到右比较相邻元素 arr[j] 和 arr[j + 1]，如果左边更大就交换。每轮结束后，最大的元素会“冒泡”到右侧已排序区间。

void bubbleSort(int *arr) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // swap(arr[j], arr[j+1]); 也可以直接调用 swap()
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
