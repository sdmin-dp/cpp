希尔排序

希尔排序是带间隔 gap 的插入排序：先按较大的 gap 分组后移，再不断缩小 gap，最后当 gap = 1 时完成一次普通插入排序。

void shell_sort(int *arr) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j = i;
            while (j >= gap && temp < arr[j - gap]) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            arr[j] = temp;
        }
    }
}
