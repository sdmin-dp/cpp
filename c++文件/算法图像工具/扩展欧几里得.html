从递归式推出回溯公式：完整推导

这是 exgcd 最关键的一步

1. 假设更小的问题已经求出

递归调用 exgcd(b, a % b) 返回一组系数 x₁, y₁。按照函数的含义，它们一定满足：

b x₁ + (a mod b) y₁ = d

其中 d = gcd(b, a mod b) = gcd(a, b)。

2. 把“取模”改写成普通四则运算

令 q = floor(a / b)。带余除法告诉我们：

a mod b = a - q b

也就是 a = qb + r、r = a mod b。这个等价替换正是递归和原问题之间的桥梁。

3. 代入并展开括号

把 a mod b = a - qb 代回递归式：

b x₁ + (a - qb)y₁ = d

= b x₁ + a y₁ - qb y₁

= a y₁ + b(x₁ - qy₁) = d

4. 与原问题对比系数

原问题希望得到 ax + by = d。整理后的递归式已经具有完全相同的结构：

a · x + b · y
↔
a · y₁ + b · (x₁-qy₁)

因此直接读取对应位置的系数，就得到：

x = y₁，y = x₁ - floor(a / b)y₁

函数含义

调用 exgcd(a,b,x,y) 后，返回值是 gcd(a,b)，引用参数满足 ax+by=gcd(a,b)。
1

递归向下只负责把 (a,b) 变成更小的 (b,a%b)。

2

b=0 时，a·1+0·0=a，所以边界系数是 (1,0)。

3

真正计算系数发生在回溯阶段：x=y₁，y=x₁-qy₁。

默认样例 99 与 78 最终得到：99 × (-11) + 78 × 14 = 3。
