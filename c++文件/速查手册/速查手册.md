## 第一章 运算符：C++ 的「武功招式」 ⚔️

运算符就是 C++ 的「武功招式」，不同的招式有不同的「威力」。

### 算术运算符：基础「招式」

| 运算符 | 名称       | 例子     | 结果   |
|--------|------------|----------|--------|
| `+`    | 加法       | `3 + 2`  | `5`    |
| `-`    | 减法       | `3 - 2`  | `1`    |
| `*`    | 乘法       | `3 * 2`  | `6`    |
| `/`    | 除法       | `3 / 2`  | `1`    |
| `%`    | 取模       | `3 % 2`  | `1`    |

**注意**：
- 整数除法会「砍掉」小数部分，比如 `3 / 2 = 1`。
- 取模运算 `%` 只能用于整数。

**互动练习**：
- 计算 `7 / 3` 和 `7 % 3` 的结果。

### 关系运算符：比较「高下」

| 运算符 | 名称       | 例子     | 结果   |
|--------|------------|----------|--------|
| `==`   | 等于       | `3 == 2` | `false`|
| `!=`   | 不等于     | `3 != 2` | `true` |
| `>`    | 大于       | `3 > 2`  | `true` |
| `<`    | 小于       | `3 < 2`  | `false`|
| `>=`   | 大于等于   | `3 >= 2` | `true` |
| `<=`   | 小于等于   | `3 <= 2` | `false`|

**互动练习**：
- 比较 `5` 和 `3` 的大小，写出所有可能的比较结果。

## 第三章 分支：编程的「选择困难症」 🤔

分支就是编程的「选择困难症」，根据不同的条件选择不同的「道路」。

### if 语句：简单「选择」

**例子**：
```cpp
if (a > b) {
    cout << "a is greater than b";
} else {
    cout << "a is not greater than b";
}
```

**互动练习**：

### switch 语句：多重「选择」

**例子**：
```cpp
switch (grade) {
    case 'A':
        cout << "Excellent!";
        break;
    case 'B':
        cout << "Good!";
        break;
    default:
        cout << "Invalid grade";
}
```

## 第六章 排序：编程的「整理术」 🧹

排序就是编程的「整理术」，把「宝贝」按顺序排好。

### 冒泡排序：简单「整理」

**例子**：
```cpp
for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - i - 1; j++) {
        if (arr[j] > arr[j + 1]) {
            swap(arr[j], arr[j + 1]);
        }
    }
}
```

**互动练习**：
- 用冒泡排序对 `{5, 3, 8, 4, 2}` 进行排序。

---

### 快速排序：高效「整理」

**例子**：
```cpp
void quickSort(int arr[], int left, int right) {
    if (left >= right) return;
    int pivot = arr[left];
    int i = left, j = right;
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        arr[i] = arr[j];
        while (i < j && arr[i] <= pivot) i++;
        arr[j] = arr[i];
    }
    arr[i] = pivot;
    quickSort(arr, left, i - 1);
    quickSort(arr, i + 1, right);
}
```

**互动练习**：
- 用快速排序对 `{5, 3, 8, 4, 2}` 进行排序。
