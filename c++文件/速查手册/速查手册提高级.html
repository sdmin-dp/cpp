第一章 类、结构体与算法封装

提高组中的 class 不是为了写大型软件，而是把“数据、规则、操作、不变量”装进一个可以直接复用的算法模块。

记忆点：外部只负责调用，内部负责保证正确。

1. struct 与 class

二者都可以有成员变量、成员函数、构造函数和运算符重载。核心区别只有默认访问权限：

写法 默认成员权限 默认继承权限 竞赛中的常见用途
struct public public 轻量记录、边、点、状态
class private private 封装树状数组、并查集、矩阵等完整模块 
struct node {
	int x, y;           // 外部可以直接访问
};

class Counter {
private:
	int x;              // 外部不能直接修改
public:
	Counter() : x(0) {}
	void add() { x++; }
	int get() const { return x; }
};

选法：只有数据时用 struct node；需要保护内部状态、统一初始化和提供完整操作时用 class。

2. 对象、成员与访问控制

class Range {
private:
	int l, r;

public:
	void set(int x, int y) {
		l = x;
		r = y;
	}

	int len() const {
		return r - l + 1;
	}
};
  • private：只能由类内部访问，用来保护不变量。
  • public：外部可以调用，是模块提供的接口。
  • protected：主要服务继承，竞赛模板中很少需要。
  • 成员函数内部可以直接使用 l、r，完整写法其实是 this->l、this->r。

3. 构造函数与初始化列表

构造函数与类同名，没有返回类型，在创建对象时自动执行。

class Point {
private:
	int x, y;

public:
	Point() : x(0), y(0) {}                    // 默认构造
	Point(int a, int b) : x(a), y(b) {}        // 带参数构造
	int get_x() const { return x; }
	int get_y() const { return y; }
};

Point a;          // 调用 Point()
Point b(3, 5);    // 调用 Point(int, int)

初始化列表比“先默认生成，再赋值”更直接；常量成员、引用成员必须在初始化列表中初始化。

class Limit {
private:
	const int n;
public:
	Limit(int x) : n(x) {}
};

4. 成员函数后的 const

class Point {
private:
	int x, y;
public:
	Point(int a = 0, int b = 0) : x(a), y(b) {}
	int get_x() const { return x; }

get_x() const 表示函数不会修改对象。比较运算符、查询函数通常都应加 const。

const Point a(3, 5);

// a.move(1);        // 错误：const 对象不能调用会修改对象的函数

5. 参数传递与返回值

写法 是否复制 能否修改原对象 常见用途
node a 是 否 小对象，确实需要副本
const node &a 否 否 比较、查询，最常用
node &a 否 是 修改外部对象
node *a 否 是 允许空指针或需要指针运算 
bool cmp(const node &a, const node &b) {
	if (a.x != b.x) return a.x < b.x;
	return a.y < b.y;
}

大对象优先使用 const &，避免不必要的复制。

6. 运算符重载

6.1 成员形式

struct node {
	int x, y;

	bool operator < (const node &b) const {
		if (x != b.x) return x < b.x;
		return y < b.y;
	}

	bool operator == (const node &b) const {
		return x == b.x && y == b.y;
	}
};

a < b 会转成 a.operator<(b)。排序比较必须满足严格弱序，不能写 x <= b.x。

6.2 非成员形式

struct node {
	int x, y;
};

node operator + (const node &a, const node &b) {
	return node{a.x + b.x, a.y + b.y};
}

当左右操作数地位相同时，非成员形式更自然。

6.3 输入输出运算符

struct node {
	int x, y;
};

istream& operator >> (istream &in, node &a) {
	in >> a.x >> a.y;
	return in;
}

ostream& operator << (ostream &out, const node &a) {
	out << a.x << ' ' << a.y;
	return out;
}

返回流的引用，才能连续写 cin >> a >> b、cout << a << b。

7. static 成员

静态成员属于整个类，不属于某一个对象。

class IdMaker {
private:
	static int cnt;
	int id;
public:
	IdMaker() : id(++cnt) {}
	int get_id() const { return id; }
};

int IdMaker::cnt = 0;   // 类外定义一次

竞赛中使用频率不高，常见于统一编号、统计对象数量。普通全局变量更简单时，不必强行使用。

8. 组合：类中包含其他对象

struct node {
	int to, w;
};

class Graph {
private:
	int n;
	vector<vector<node> > g;

public:
	Graph(int n = 0) : n(n), g(n + 1) {}

	void add_edge(int u, int v, int w) {
		g[u].push_back(node{v, w});
	}

	const vector<node>& edges(int u) const {
		return g[u];
	}
};

这叫组合，不需要继承。OI 算法封装几乎都可以用组合完成。

9. 函数模板

模板让同一份逻辑服务多种类型。

template <class T>
T my_max(const T &a, const T &b) {
	return a < b ? b : a;
}

使用：

int a = my_max(3, 5);
double b = my_max(2.5, 1.8);

两个实参必须能推导出兼容的同一种 T，并且类型要支持 <。

10. 类模板

template <class T>
class Fenwick {
private:
	int n;
	vector<T> tr;

public:
	Fenwick(int n = 0) : n(n), tr(n + 1, 0) {}

	void add(int x, T v) {
		for (int i = x; i <= n; i += i & -i)
			tr[i] += v;
	}

	T sum(int x) const {
		T ans = 0;
		for (int i = x; i > 0; i -= i & -i)
			ans += tr[i];
		return ans;
	}

	T query(int l, int r) const {
		return sum(r) - sum(l - 1);
	}
};
Fenwick<int> cnt(n);          // 维护数量
Fenwick<long long> val(n);    // 维护和

T 必须支持默认值 0、加法和减法。

11. 封装并查集

class DSU {
private:
	vector<int> fa, sz;

public:
	DSU(int n = 0) : fa(n + 1), sz(n + 1, 1) {
		for (int i = 1; i <= n; i++) fa[i] = i;
	}

	int find(int x) {
		return fa[x] == x ? x : fa[x] = find(fa[x]);
	}

	bool same(int x, int y) {
		return find(x) == find(y);
	}

	bool merge(int x, int y) {
		x = find(x);
		y = find(y);
		if (x == y) return false;
		if (sz[x] < sz[y]) swap(x, y);
		fa[y] = x;
		sz[x] += sz[y];
		return true;
	}

	int size(int x) {
		return sz[find(x)];
	}
};

封装收益：主程序看不到 fa，不会绕过 find 错误地读取代表元。

12. 封装矩阵

const long long mod = 1000000007;

class Matrix {
private:
	int n, m;
	vector<vector<long long> > a;

public:
	Matrix(int n = 0, int m = 0, bool one = false)
		: n(n), m(m), a(n, vector<long long>(m, 0)) {
		if (one)
			for (int i = 0; i < min(n, m); i++) a[i][i] = 1;
	}

	vector<long long>& operator [] (int x) { return a[x]; }
	const vector<long long>& operator [] (int x) const { return a[x]; }

	Matrix operator * (const Matrix &b) const {
		Matrix c(n, b.m);
		for (int i = 0; i < n; i++)
			for (int k = 0; k < m; k++)
				for (int j = 0; j < b.m; j++)
					c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % mod;
		return c;
	}
};

模块仍然要检查维数相容：左矩阵列数必须等于右矩阵行数。

13. 封装中的初始化与清空

多测题不要依赖“全局数组初始为零”。把初始化职责放进构造函数或 init：

class Solver {
private:
	int n;
	vector<int> a;
public:
	void init(int m) {
		n = m;
		a.assign(n + 1, 0);
	}
};
  • resize 改变长度，旧元素可能保留。
  • assign 重新设置长度和所有元素，适合多测清空。
  • 大对象放在局部可能爆栈，封装时优先使用 vector 或全局对象。

14. 什么时候不该封装

  • 只出现一次的三行操作，没有形成完整模块。
  • 封装后仍需要频繁访问所有内部数组，接口反而更绕。
  • 极限常数题中，层层动态分配和虚函数会增加成本。
  • 为了“看起来高级”而制造继承层次。

判断标准：封装是否减少主流程中的状态数量，是否让错误更难发生。

15. 类模板自检

  • 构造函数是否完成所有初始化？
  • 查询函数是否应写成 const？
  • 大对象参数是否使用 const &？
  • 比较运算是否满足严格弱序？

第二章 分治、扫描线与离线思想

1. 分治三步

  1. 把原问题拆成规模更小的同类问题。
  2. 递归求解子问题。
  3. 在线性或较低复杂度内合并答案。

通用骨架：

void divide(int l, int r) {
	if (l == r) return;
	int m = (l + r) >> 1;
	divide(l, m);
	divide(m + 1, r);
	merge_answer(l, m, r);
}

记忆点：分治能否成功，关键不在“递归”，而在“合并是否足够快”。

3. 折半搜索

适用信号：n 约为 35~45，直接 2^n 超时，但 2^(n/2) 可行。

子集和不超过 m 的最大值：

void get_sum(int l, int r, vector<long long> &v) {
	int len = r - l + 1;
	for (int s = 0; s < (1 << len); s++) {
		long long sum = 0;
		for (int i = 0; i < len; i++)
			if (s >> i & 1) sum += a[l + i];
		if (sum <= m) v.push_back(sum);
	}
}

long long meet_in_middle(int n) {
	vector<long long> x, y;
	int mid = n >> 1;
	get_sum(1, mid, x);
	get_sum(mid + 1, n, y);
	sort(y.begin(), y.end());
	long long ans = 0;
	for (int i = 0; i < (int)x.size(); i++) {
		vector<long long>::iterator it = upper_bound(y.begin(), y.end(), m - x[i]);
		if (it != y.begin()) ans = max(ans, x[i] + *--it);
	}
	return ans;
}

复杂度约 O(2^(n/2) n)，空间 O(2^(n/2))。

4. 扫描线

把区间 [l,r] 的进入和离开变成事件：

struct node {
	int x, d;
	bool operator < (const node &b) const {
		if (x != b.x) return x < b.x;
		return d > b.d;
	}
};

vector<node> e;
e.push_back(node{l, 1});
e.push_back(node{r, -1});

必须先确定区间是闭区间、开区间还是半开区间，再决定同坐标事件顺序。

扫描线四问：

  1. 扫描坐标是什么？
  2. 进入和离开事件是什么？
  3. 扫描过程中维护什么？
  4. 相邻事件之间如何累计贡献？

5. 离线询问

离线不要求立刻回答，可以先重排询问。

典型组合：

  • 按右端点排序询问 + 树状数组。
  • 按边权排序询问 + 并查集。
  • 按时间排序修改与查询。
  • DFS 序把子树转成区间，再离线处理。

6. 快速选择

只求第 k 小，不要求整体有序，可以使用随机划分。期望复杂度 O(n)。

int quick_select(int l, int r, int k) {
	if (l == r) return a[l];
	int p = uniform_int_distribution<int>(l, r)(rng);
	swap(a[p], a[r]);
	int j = l;
	for (int i = l; i < r; i++)
		if (a[i] < a[r]) swap(a[i], a[j++]);
	swap(a[j], a[r]);
	if (k == j) return a[j];
	if (k < j) return quick_select(l, j - 1, k);
	return quick_select(j + 1, r, k);
}

这里 k 是数组下标。大量重复值时可改成三路划分，避免相等元素造成极不平衡的递归。

7. 分治统计跨区间贡献

分治计数的通用结构：左半答案、右半答案、跨越中点的答案。

long long solve(int l, int r) {
	if (l == r) return base(l);
	int m = (l + r) >> 1;
	long long ans = solve(l, m) + solve(m + 1, r);
	ans += count_cross(l, m, r);
	return ans;
}

count_cross 常通过双指针、排序后的单调性、前缀最值完成。若跨区间仍需二次枚举，整体通常不能降到 O(n log n)。

8. 按右端点离线

询问区间 [l,r]，信息随右端点单调加入时：

sort(q + 1, q + m + 1, [](const node &a, const node &b) {
	return a.r < b.r;
});

int p = 1;
for (int i = 1; i <= m; i++) {
	while (p <= q[i].r) {
		add_position(p);
		p++;
	}
	ans[q[i].id] = query(q[i].l, q[i].r);

典型例子是区间不同数字个数：加入位置 p 时，将同值上一次出现位置减 1，当前位置加 1，再查询区间和。

第三章 单调结构与哈希表

1. 单调栈

求每个位置右侧第一个严格更大的位置：

void next_greater(int n) {
	stack<int> st;
	for (int i = n; i >= 1; i--) {
		while (!st.empty() && a[st.top()] <= a[i]) st.pop();
		nxt[i] = st.empty() ? 0 : st.top();
		st.push(i);
	}
}

栈中保存的是“仍可能成为后续答案”的下标。

相等规则：

  • 求严格更大：弹出 <=。
  • 求大于等于：弹出 <。
  • 贡献法中左右两侧通常一边严格、一边非严格，避免重复计数。

2. 柱状图最大矩形

long long largest_rectangle(int n) {
	stack<int> st;
	long long ans = 0;
	a[0] = a[n + 1] = 0;
	st.push(0);
	for (int i = 1; i <= n + 1; i++) {
		while (a[st.top()] > a[i]) {
			int p = st.top();
			st.pop();
			long long w = i - st.top() - 1;
			ans = max(ans, a[p] * w);
		}
		st.push(i);
	}
	return ans;
}

3. 单调队列

固定长度 k 的滑动窗口最大值：

void window_max(int n, int k) {
	deque<int> q;
	for (int i = 1; i <= n; i++) {
		while (!q.empty() && q.front() < i - k + 1) q.pop_front();
		while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
		q.push_back(i);
		if (i >= k) ans[i - k + 1] = a[q.front()];
	}
}

队首处理过期，队尾维护单调性。每个下标最多进队、出队一次，总复杂度 O(n)。

4. 哈希表：链地址法

const int P = 100003;
vector<int> h[P];

int get_hash(int x) {
	x %= P;
	if (x < 0) x += P;
	return x;
}

bool find_hash(int x) {
	int p = get_hash(x);
	for (int i = 0; i < (int)h[p].size(); i++)
		if (h[p][i] == x) return true;
	return false;
}

void insert_hash(int x) {
	if (!find_hash(x)) h[get_hash(x)].push_back(x);
}

5. 开放寻址

const int P = 200003;
const int EMPTY = 0x3f3f3f3f;
int h[P];

int locate(int x) {
	int p = (x % P + P) % P;
	while (h[p] != EMPTY && h[p] != x) {
		p++;
		if (p == P) p = 0;
	}
	return p;
}

开放寻址删除时不能直接恢复为空，否则会截断后续元素的探测链；需要删除标记。

7. 子数组最小值贡献

把“枚举所有子数组”改成“枚举每个位置作为最小值贡献多少次”。

令 L[i] 为左侧第一个严格小于 a[i] 的位置，R[i] 为右侧第一个小于等于 a[i] 的位置，则：

贡献=a[i]×(i-L[i])×(R[i]-i)

一边严格、一边非严格，才能让相等最小值只由一个位置负责。

stack<int> st;

第四章 搜索进阶

1. 剪枝清单

剪枝 判断方式
可行性 当前状态已经违反规则
最优性 当前代价已经不优于答案
上下界 即使后面全部最优也无法改进答案
重复状态 相同状态已用更优代价到达
对称性 多种选择本质等价，只保留一种
搜索顺序 先尝试更可能成功或更紧的选择

剪枝必须证明“被删掉的分支不可能产生需要的答案”。

2. 迭代加深

答案深度小、分支多、普通 BFS 内存大时使用。

bool dfs(int dep, int lim) {
	if (dep == lim) return check();
	if (dep + estimate() > lim) return false;
	for (int i = 0; i < cnt; i++) {
		if (!can(i)) continue;
		do_move(i);
		if (dfs(dep + 1, lim)) return true;
		undo_move(i);
	}
	return false;
}

}

优先级：

7. 分支限界：01 选择

先按单位收益等策略排序，预处理剩余收益上界。若当前收益加上所有剩余可能收益仍不超过答案，直接剪枝。

void dfs(int p, int w, int v) {
	if (w > m) return;
	if (v + suf[p] <= ans) return;
	if (p > n) {
		ans = max(ans, v);
		return;
	}
	dfs(p + 1, w, v);
	dfs(p + 1, w + a[p].w, v + a[p].v);
}

这里 suf[p] 必须是真正的乐观上界。上界低估会错误剪掉最优解，上界过松只会让剪枝效果变差。

8. A* 与 Dijkstra 的关系

  • h(x)=0 时，A* 就是 Dijkstra。
  • h 不高估时，第一次从优先队列取出终点可得到最优解。
  • h 越接近真实剩余代价，扩展状态越少。
  • 若 h 可能高估，只能把它当搜索顺序启发，不能保证最优。

八数码常用曼哈顿距离；若逆序奇偶性与目标不同，可以在搜索前直接判无解。

3. 状压 DP：TSP

dp[s][i]：已经访问集合 s，当前停在 i 的最小代价。

int tsp(int n) {
	int S = 1 << n;
	memset(dp, 0x3f, sizeof dp);
	dp[1][0] = 0;
	for (int s = 1; s < S; s++) {
		for (int i = 0; i < n; i++) {
			if (!(s >> i & 1)) continue;
			for (int j = 0; j < n; j++) {
				if (s >> j & 1) continue;
				int ns = s | (1 << j);
				dp[ns][j] = min(dp[ns][j], dp[s][i] + w[i][j]);
			}
		}
	}
	return dp[S - 1][n - 1];
}

复杂度 O(n^2 2^n)，空间 O(n2^n)。

第六章 最短路与图上路径进阶

1. 统一理解：松弛

if (d[v] > d[u] + w) {
	d[v] = d[u] + w;
}

最短路算法的主要区别是：按什么顺序选择可松弛的点或边。

2. Bellman-Ford

bool bellman_ford(int n, int m, int s) {
	for (int i = 1; i <= n; i++) d[i] = INF;
	d[s] = 0;
	for (int k = 1; k < n; k++) {
		bool changed = false;
		for (int i = 1; i <= m; i++) {
			int u = e[i].u, v = e[i].v, w = e[i].w;
			if (d[u] != INF && d[v] > d[u] + w) {
				d[v] = d[u] + w;
				changed = true;
			}
		}
		if (!changed) break;
	}
	for (int i = 1; i <= m; i++)
		if (d[e[i].u] != INF && d[e[i].v] > d[e[i].u] + e[i].w)
			return false;
	return true;
}

返回 false 表示存在从起点可达的负环。复杂度 O(nm)。

3. SPFA 与负环

bool spfa(int n, int s) {
	queue<int> q;
	for (int i = 1; i <= n; i++) d[i] = INF;
	d[s] = 0; q.push(s); inq[s] = true;
	while (!q.empty()) {
		int u = q.front(); q.pop(); inq[u] = false;
		for (int i = head[u]; i; i = e[i].nxt) {
			int v = e[i].to, w = e[i].w;
			if (d[v] > d[u] + w) {
				d[v] = d[u] + w;
				cnt[v] = cnt[u] + 1;
				if (cnt[v] >= n) return false;
				if (!inq[v]) q.push(v), inq[v] = true;
			}
		}
	}
	return true;
}

SPFA 最坏复杂度仍可退化为 O(nm)，不能把它当作稳定的快速算法。

第七章 二分图

二分图的核心不是“把点染成两种颜色”，而是边只在左右两部之间连接。这个结构让一般图中的许多困难问题转化为匹配问题。

1. 定义、判定与奇环

若顶点能分成互不相交的集合 L、R，每条边的一端在 L，另一端在 R，则图是二分图。

等价结论：

  1. 图可以用两种颜色染色，相邻点颜色不同。
  2. 图中不存在长度为奇数的环。

DFS 染色

bool color_dfs(int u, int c) {
	col[u] = c;
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (!col[v]) {
			if (!color_dfs(v, 3 - c)) return false;
		} else if (col[v] == c) {
			return false;
		}
	}
	return true;
}

bool is_bipartite(int n) {
	for (int i = 1; i <= n; i++)
		if (!col[i] && !color_dfs(i, 1)) return false;
	return true;
}

BFS 染色

bool color_bfs(int s) {
	queue<int> q;
	q.push(s);
	col[s] = 1;
	while (!q.empty()) {
		int u = q.front();
		q.pop();
		for (int i = head[u]; i; i = e[i].nxt) {
			int v = e[i].to;
			if (!col[v]) {
				col[v] = 3 - col[u];
				q.push(v);
			} else if (col[v] == col[u]) {
				return false;
			}
		}
	}
	return true;
}

图可能不连通，外层必须枚举每个未染色点。自环会立刻导致非二分图；重边不影响染色结论。

2. 匹配、最大匹配与增广路

  • 匹配：选出若干条没有公共端点的边。
  • 匹配点：已经被某条匹配边使用的点。
  • 非匹配点：还没有匹配边的点。
  • 增广路：从非匹配点出发，按“非匹配边、匹配边”交替经过，最终到达另一个非匹配点。

把增广路上的边全部取反：原匹配边删除，原非匹配边加入，匹配数恰好增加 1。

3. 匈牙利算法

邻接表只需要从左部点连向右部点。

bool match_dfs(int u) {
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (vis[v]) continue;
		vis[v] = true;
		if (!mat_r[v] || match_dfs(mat_r[v])) {
			mat_r[v] = u;
			mat_l[u] = v;
			return true;
		}
	}
	return false;
}

int hungarian(int nl) {
	int ans = 0;
	for (int u = 1; u <= nl; u++) {
		memset(vis, 0, sizeof vis);
		if (match_dfs(u)) ans++;
	}
	return ans;
}
  • vis 每轮清空，表示这一次增广已经尝试过的右部点。
  • mat_r[v] 是右部点 v 当前匹配的左部点。
  • 同时记录 mat_l[u]，便于输出方案和构造其他结论。
  • 复杂度 O(VE)，稠密图也常写作 O(n^3)。

4. Hopcroft-Karp

当点边规模较大时，匈牙利算法可能超时。Hopcroft-Karp 每轮 BFS 同时找到最短增广路的层次，再用 DFS 批量增广，复杂度 O(E sqrt(V))。

bool hk_bfs(int nl) {
	queue<int> q;
	for (int u = 1; u <= nl; u++) {
		if (!mat_l[u]) dis[u] = 0, q.push(u);
		else dis[u] = -1;
	}
	bool ok = false;
	while (!q.empty()) {
		int u = q.front();
		q.pop();
		for (int i = head[u]; i; i = e[i].nxt) {
			int v = e[i].to;
			int w = mat_r[v];
			if (!w) ok = true;
			else if (dis[w] == -1) {
				dis[w] = dis[u] + 1;
				q.push(w);
			}
		}
	}
	return ok;
}

bool hk_dfs(int u) {
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		int w = mat_r[v];
		if (!w || (dis[w] == dis[u] + 1 && hk_dfs(w))) {
			mat_l[u] = v;
			mat_r[v] = u;
			return true;
		}
	}
	dis[u] = -1;
	return false;
}

int hopcroft_karp(int nl) {
	int ans = 0;
	while (hk_bfs(nl))
		for (int u = 1; u <= nl; u++)
			if (!mat_l[u] && hk_dfs(u)) ans++;
	return ans;
}

hk_dfs 只沿 BFS 建出的层次前进；失败点标记为 -1，避免本轮重复搜索。

5. 最小点覆盖

点覆盖：选择一些点，使每条边至少有一个端点被选择。

Kőnig 定理只对二分图成立：

最小点覆盖数=最大匹配数

构造最小点覆盖方案

  1. 从所有未匹配的左部点出发。
  2. 左到右只走非匹配边。
  3. 右到左只走匹配边。
  4. 记所有到达的左部点为 ZL，右部点为 ZR。
  5. 最小点覆盖为 (L - ZL) + ZR。
void cover_dfs(int u) {
	vis_l[u] = true;
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (mat_l[u] == v || vis_r[v]) continue;
		vis_r[v] = true;
		if (mat_r[v] && !vis_l[mat_r[v]])
			cover_dfs(mat_r[v]);
	}
}

for (int u = 1; u <= nl; u++)
	if (!mat_l[u]) cover_dfs(u);

// 方案：所有 !vis_l[u] 的左部点，加上所有 vis_r[v] 的右部点。

6. 最大独立集

独立集：任意两个被选点之间都没有边。

在二分图中：

最大独立集数=总点数-最大匹配数

原因：独立集的补集是点覆盖。最小点覆盖最少，补集就最大。

构造方案：求出最小点覆盖后，选择所有不在覆盖中的点。

“最大独立集 = 点数 - 最大匹配”不能直接用于一般图。

7. 最小边覆盖

边覆盖：选择一些边，使每个顶点至少是某条所选边的端点。

若图中没有孤立点：

最小边覆盖数=总点数-最大匹配数

构造：先选最大匹配中的边；每个仍未覆盖的点，再任选一条与它相连的边。

有孤立点时不存在覆盖所有点的边覆盖，必须先按题意单独处理。

8. DAG 最小路径覆盖

问题：用尽量少的点不重复有向路径覆盖 DAG 的全部顶点。

拆点建二分图：

  1. 每个原点 u 拆成左部 uL 和右部 uR。
  2. 原边 u -> v 转成二分图边 uL -> vR。
  3. 求最大匹配 match。
最小路径覆盖数=n-match

匹配边表示“把 v 接在 u 后面”。未被任何匹配边指向的点是每条路径的起点。

for (int u = 1; u <= n; u++)
	if (!mat_r[u]) {
		for (int x = u; x; x = mat_l[x])
			cout << x << ' ';
		cout << '\n';
	}

前提是原图为 DAG，且每个点只能出现一次。允许路径重复经过点时不是这个模型。

9. 网格和棋盘建图

网格中上下左右移动会让 (x+y) 的奇偶性改变，因此天然二分：

  • (x+y)%2==0 放左部。
  • (x+y)%2==1 放右部。
  • 相邻可配对格子连边。

常见题型：

10. 带权完美匹配：KM 入口

当每条左右匹配边有权，要求完美匹配的最大权值时，使用 KM 算法。它维护可行顶标：

lx[u]+ly[v]≥ w[u][v]

只有等号边属于相等子图；在相等子图中不断寻找增广路，失败时按最小松弛量调整顶标。

long long km(int n) {
	vector<long long> u(n + 1), v(n + 1);
	vector<int> p(n + 1), pre(n + 1);
	for (int i = 1; i <= n; i++) {
		p[0] = i;
		int j0 = 0;
		vector<long long> minv(n + 1, INF);
		vector<bool> used(n + 1, false);
		do {
			used[j0] = true;
			int i0 = p[j0], j1 = 0;
			long long delta = INF;
			for (int j = 1; j <= n; j++) if (!used[j]) {
				long long cur = -w[i0][j] - u[i0] - v[j];
				if (cur < minv[j]) minv[j] = cur, pre[j] = j0;
				if (minv[j] < delta) delta = minv[j], j1 = j;
			}
			for (int j = 0; j <= n; j++) {
				if (used[j]) u[p[j]] += delta, v[j] -= delta;
				else minv[j] -= delta;
			}
			j0 = j1;
		} while (p[j0] != 0);
		do {
			int j1 = pre[j0];
			p[j0] = p[j1];
			j0 = j1;
		} while (j0);
	}
	long long ans = 0;
	for (int j = 1; j <= n; j++) ans += w[p[j]][j];
	return ans;
}

缺边时可补极小权值，但最终必须检查答案是否使用了不存在的边。求最小权完美匹配可把权值取负，或调整顶标方向。

第八章 Tarjan 与图的连通性

Tarjan 不是单一算法，而是一组利用 DFS 树、时间戳和 low 值识别连通结构的方法。第一步必须先分清题目是有向图还是无向图。

图类型 常见目标 low 的含义
有向图 强连通分量 SCC 仍在栈内的可达祖先的最小 dfn
无向图 割点、桥、点双、边双 DFS 子树经返祖边能到达的最小 dfn

1. DFS 树、dfn 与 low

  • dfn[u]：第一次访问 u 的时间戳，也是 DFS 序中的发现次序。
  • 树边：DFS 第一次走到未访问点时使用的边。
  • 返祖边：从当前子树连回祖先的非树边。
  • low[u]：当前 DFS 子树能够“绕回去”的最早位置。

记忆点：dfn 是出生时间，low 是不经过父边能够回到的最早祖先。

2. 有向图强连通分量 SCC

强连通分量中的任意两点互相可达。把每个 SCC 缩成一个点后，图一定是 DAG。

更新规则

遍历有向边 u -> v：

  1. v 未访问：递归后用 low[v] 更新 low[u]。
  2. v 已访问且仍在栈内：用 dfn[v] 更新 low[u]。
  3. v 已经出栈：它属于已经结束的 SCC，不能更新。

第二种情况必须写 dfn[v]，不要不加思考地写 low[v]。

完整模板

void tarjan_scc(int u) {
	dfn[u] = low[u] = ++tim;
	st[++top] = u;
	ins[u] = true;

	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (!dfn[v]) {
			tarjan_scc(v);
			low[u] = min(low[u], low[v]);
		} else if (ins[v]) {
			low[u] = min(low[u], dfn[v]);
		}
	}

	if (dfn[u] == low[u]) {
		++scc;
		while (true) {
			int v = st[top--];
			ins[v] = false;
			bel[v] = scc;
			sz[scc]++;
			if (v == u) break;
		}
	}
}

void build_scc(int n) {
	for (int i = 1; i <= n; i++)
		if (!dfn[i]) tarjan_scc(i);
}

复杂度 O(V+E)。SCC 编号通常按出栈顺序产生，常常与拓扑序相反，但不要依赖这一细节代替显式拓扑排序。

3. SCC 手工模拟

有向边：1->2, 2->3, 3->1, 3->4, 4->5, 5->4。

返回位置 dfn 变化 low 变化 栈 结论
访问 1,2,3 1,2,3 low[3]=1 1,2,3 3->1 回到祖先
访问 4,5 4,5 low[5]=4 1,2,3,4,5 5->4 形成环
返回 4 不变 low[4]=4 弹出 5,4 SCC {4,5}
返回 1 不变 low[1]=1 弹出 3,2,1 SCC {1,2,3}

不要看到 low[u] 相同就直接判定同一 SCC；真正的分量边界是 dfn[u]==low[u] 时的出栈过程。

4. SCC 缩点

缩点后把分量权值合并，再处理 DAG。

for (int u = 1; u <= n; u++) {
	val[bel[u]] += w[u];
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (bel[u] != bel[v])
			g[bel[u]].push_back(bel[v]);
	}
}

for (int u = 1; u <= scc; u++) {
	sort(g[u].begin(), g[u].end());
	g[u].erase(unique(g[u].begin(), g[u].end()), g[u].end());
	for (int v : g[u]) indeg[v]++;
}

重复边不一定影响最长路值，但会影响入度统计和方案数，稳妥做法是去重。

缩点 DAG 最长权值路径

queue<int> q;
for (int u = 1; u <= scc; u++) {
	dp[u] = val[u];
	if (!indeg[u]) q.push(u);
}

while (!q.empty()) {
	int u = q.front();
	q.pop();
	for (int v : g[u]) {
		dp[v] = max(dp[v], dp[u] + val[v]);
		if (--indeg[v] == 0) q.push(v);
	}
}

5. SCC 入度、出度与加边

缩点 DAG 中：

  • 入度为 0 的 SCC 无法从其他 SCC 到达。
  • 出度为 0 的 SCC 无法继续到达其他 SCC。
  • 从若干指定点出发覆盖全图，通常关注入度为 0 的 SCC。
  • 若整个图只有一个 SCC，不需要加边。
  • 否则，使有向图变成强连通图的最少加边数为：
max(入度为0的SCC数,出度为0的SCC数)

结论适用于允许在任意 SCC 之间补边的模型。

6. 2-SAT

每个布尔变量 x 拆成两个点：x 与 not x。蕴含关系建有向边。

子句 (a or b) 等价于：

  • not a -> b
  • not b -> a
int id(int x, bool val) {
	return x * 2 + (val ? 0 : 1);
}

void add_clause(int x, bool xv, int y, bool yv) {
	add_edge(id(x, !xv), id(y, yv));
	add_edge(id(y, !yv), id(x, xv));
}

求 SCC 后，若某变量的真点和假点在同一 SCC，则无解。

bool check_2sat(int n) {
	for (int x = 0; x < n; x++)
		if (bel[id(x, true)] == bel[id(x, false)]) return false;
	return true;
}

常见限制转子句：

限制 子句或建边
a 和 b 至少一个真 (a or b)
a 和 b 不能同时真 (not a or not b)
a 真则 b 真 a -> b，即 (not a or b)
a、b 相同 a->b, b->a, not a->not b, not b->not a
a、b 不同 a->not b, b->not a, not a->b, not b->a

方案赋值与 SCC 编号方向有关。最稳妥的方法是建立缩点 DAG 后按逆拓扑序赋值，不要死记 bel[x] < bel[not x]。

7. 无向图父边处理

无向边必须成对加入，边编号满足 i^1 为反向边。建议第一条边编号从 0 或 2 开始。

void add_undirected(int u, int v) {
	add_edge(u, v);
	add_edge(v, u);
}

DFS 参数传入“进入当前点的边编号”，跳过的只能是这条边的反向边。只写 v != fa 会把平行边也误认为父边，导致重边图判断错误。

8. 桥

树边 u-v 是桥，当且仅当 v 的子树无法绕回 u 或更早祖先：

low[v]>dfn[u]
void bridge_dfs(int u, int in_edge) {
	dfn[u] = low[u] = ++tim;
	for (int i = head[u]; i != -1; i = e[i].nxt) {
		if ((i ^ 1) == in_edge) continue;
		int v = e[i].to;
		if (!dfn[v]) {
			bridge_dfs(v, i);
			low[u] = min(low[u], low[v]);
			if (low[v] > dfn[u])
				bridge[i] = bridge[i ^ 1] = true;
		} else {
			low[u] = min(low[u], dfn[v]);
		}
	}
}

删除桥会增加连通块；桥一定是 DFS 树边。

9. 边双连通分量 EBCC

边双连通分量中任意两点之间至少存在两条边不重复路径。求法：

  1. 先标记所有桥。
  2. 忽略桥，再 DFS 染色。
void color_ebcc(int u, int c) {
	bel[u] = c;
	for (int i = head[u]; i != -1; i = e[i].nxt) {
		if (bridge[i]) continue;
		int v = e[i].to;
		if (!bel[v]) color_ebcc(v, c);
	}
}

把每个 EBCC 缩成点、每座桥变成边，得到一棵树或森林，称为桥树。

常见后续：

  • 询问两点之间必经多少座桥：桥树上距离。
  • 最少加边使连通无向图变成边双连通：统计桥树叶子数 leaf，答案为 (leaf+1)/2。
  • 给一条边定向后要求强连通：原图必须没有桥。

10. 割点

删除点 u 及其关联边后，连通块数量增加，则 u 是割点。

非根节点条件：存在儿子 v 满足：

low[v]≥ dfn[u]

根节点条件：DFS 树中至少有两个独立儿子。

void cut_dfs(int u, int in_edge) {
	dfn[u] = low[u] = ++tim;
	int child = 0;
	for (int i = head[u]; i != -1; i = e[i].nxt) {
		if ((i ^ 1) == in_edge) continue;
		int v = e[i].to;
		if (!dfn[v]) {
			child++;
			cut_dfs(v, i);
			low[u] = min(low[u], low[v]);
			if (in_edge != -1 && low[v] >= dfn[u]) cut[u] = true;
		} else {
			low[u] = min(low[u], dfn[v]);
		}
	}
	if (in_edge == -1 && child >= 2) cut[u] = true;
}

割点用 >=，桥用 >。等号表示儿子可以回到 u，但不能绕过 u 回到更早祖先，所以删点会断，删边不会断。

11. 删除割点后的连通块数

若 u 不是 DFS 根，每个满足 low[v] >= dfn[u] 的儿子子树都会独立形成一块，剩余祖先方向再形成一块。

part[u] = 1;
for (每个 DFS 儿子 v)
	if (low[v] >= dfn[u]) part[u]++;

根节点没有“祖先剩余块”，删除后连通块数就是 DFS 儿子数量。若原图本来不连通，还要把其他原连通块计入总答案。

12. 点双连通分量 VBCC

点双连通分量中，任意两条边处于某个共同简单环中；不同点双分量可以共享割点，但不能共享普通边。

使用边栈：走到一条树边或返祖边时压栈；当 low[v] >= dfn[u]，从栈顶弹到树边 u-v，这些边的端点组成一个点双分量。

void vbcc_dfs(int u, int in_edge) {
	dfn[u] = low[u] = ++tim;
	int child = 0;
	for (int i = head[u]; i != -1; i = e[i].nxt) {
		if ((i ^ 1) == in_edge) continue;
		int v = e[i].to;
		if (!dfn[v]) {
			child++;
			edge_st.push_back(i);
			vbcc_dfs(v, i);
			low[u] = min(low[u], low[v]);
			if (low[v] >= dfn[u]) {
				++bcc;
				vector<int> ver;
				while (true) {
					int j = edge_st.back();
					edge_st.pop_back();
					ver.push_back(e[j].from);
					ver.push_back(e[j].to);
					if (j == i) break;
				}
				sort(ver.begin(), ver.end());
				ver.erase(unique(ver.begin(), ver.end()), ver.end());
				comp[bcc] = ver;
			}
		} else if (dfn[v] < dfn[u]) {
			edge_st.push_back(i);
			low[u] = min(low[u], dfn[v]);
		}
	}
	if (in_edge == -1 && child == 0) {
		++bcc;
		comp[bcc].push_back(u);
	}
}

边结构需要同时保存 from、to。孤立点单独构成一个点双分量。

13. 圆方树

圆方树把一般无向图转成树：

  • 原图顶点作为圆点，编号 1..n。
  • 每个点双分量新建一个方点，编号 n+1..n+bcc。
  • 方点与该点双分量中的所有原顶点相连。

割点会连接多个方点，普通点通常只属于一个非平凡点双分量。圆方树上可以继续使用 LCA、树上差分、路径统计。

典型组合：

  • 两点之间所有简单路径都必须经过哪些割点。
  • 多组路径涉及的点双分量数量。
  • 删除一个点后，某两点是否仍连通。

  • SCC 遇到栈内已访问点时是否使用 dfn[v]？

第九章 树上算法与树形 DP

1. DFS 序与子树区间

void dfs_order(int u, int fa) {
	dfn[u] = ++tim;
	sz[u] = 1;
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (v == fa) continue;
		dep[v] = dep[u] + 1;
		dfs_order(v, u);
		sz[u] += sz[v];
	}
	out[u] = tim;
}

u 的子树对应区间 [dfn[u], dfn[u] + sz[u] - 1]。

组合：

  • 子树加、子树和：DFS 序 + 树状数组 / 线段树。
  • 判断祖先：dfn[u] <= dfn[v] && out[v] <= out[u]。
  • 树上路径：LCA、差分或树链方法。

2. 树的直径

无负边权树：从任意点找到最远点 s，再从 s 找最远点 t，s-t 是一条直径。

void dfs_far(int u, int fa, long long d) {
	if (d > best) best = d, far_node = u;
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (v != fa) dfs_far(v, u, d + e[i].w);
	}
}

有负权边时，两次 DFS 的结论不能直接使用，应改用树形 DP，并明确路径是否允许为空。

3. 树形 DP 求直径

down[u]：从 u 向子树走的最大路径。

void diameter_dp(int u, int fa) {
	down[u] = 0;
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to, w = e[i].w;
		if (v == fa) continue;
		diameter_dp(v, u);
		ans = max(ans, down[u] + down[v] + w);
		down[u] = max(down[u], down[v] + w);
	}
}

更新答案必须发生在覆盖 down[u] 之前，才能组合两条不同子树路径。

4. 树的重心

删除重心后，最大连通块大小最小，并且不超过 n/2。

void centroid_dfs(int u, int fa) {
	sz[u] = 1;
	int mx = 0;
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (v == fa) continue;
		centroid_dfs(v, u);
		sz[u] += sz[v];
		mx = max(mx, sz[v]);
	}
	mx = max(mx, n - sz[u]);
	if (mx < best) best = mx, center = u;
}

树可能有一个或两个重心。

5. 换根 DP 信息流

第一遍：儿子信息向父亲汇总。

第二遍：父亲把“整棵树除去儿子子树的贡献”传给儿子。

换根时必须区分：

  • 来自当前儿子子树的贡献。
  • 来自父亲方向的贡献。
  • 来自其他兄弟子树的贡献。

常用技巧：维护最大值和次大值，向某个最大贡献儿子传递时改用次大值。

第十章 平衡树与有序数据结构

1. 需要支持的操作

操作 含义
插入 / 删除 动态维护多重集合
排名 小于 x 的元素个数加 1
第 k 小 按子树大小查找
前驱 小于 x 的最大值
后继 大于 x 的最小值

普通 BST 最坏会退化成链，操作变成 O(n)；平衡树把高度维持在 O(log n) 量级。

2. Treap 不变量

每个节点同时维护：

  1. key 满足二叉搜索树顺序。
  2. 随机优先级 pri 满足堆顺序。
  3. cnt 表示重复次数。
  4. sz 表示含重复元素的子树大小。
struct node {
	int ch[2], key, pri, cnt, sz;
} tr[N];

int root, tot;

void push_up(int p) {
	tr[p].sz = tr[tr[p].ch[0]].sz + tr[tr[p].ch[1]].sz + tr[p].cnt;
}

int new_node(int x) {
	++tot;
	tr[tot].key = x;
	tr[tot].pri = (int)rng();
	tr[tot].cnt = tr[tot].sz = 1;
	return tot;
}

3. 旋转

d=0 表示右旋，d=1 表示左旋：

void rotate(int &p, int d) {
	int q = tr[p].ch[d ^ 1];
	tr[p].ch[d ^ 1] = tr[q].ch[d];
	tr[q].ch[d] = p;
	push_up(p);
	push_up(q);
	p = q;
}

旋转改变树形，但不改变中序序列。

4. 插入与删除

void insert(int &p, int x) {
	if (!p) {
		p = new_node(x);
		return;
	}
	if (tr[p].key == x) {
		tr[p].cnt++;
	} else {
		int d = x > tr[p].key;
		insert(tr[p].ch[d], x);
		if (tr[tr[p].ch[d]].pri > tr[p].pri) rotate(p, d ^ 1);
	}
	push_up(p);
}

void erase(int &p, int x) {
	if (!p) return;
	if (tr[p].key == x) {
		if (tr[p].cnt > 1) {
			tr[p].cnt--;
		} else if (!tr[p].ch[0] || !tr[p].ch[1]) {
			p = tr[p].ch[0] + tr[p].ch[1];
			return;
		} else {
			int d = tr[tr[p].ch[0]].pri > tr[tr[p].ch[1]].pri ? 1 : 0;
			rotate(p, d);
			erase(p, x);
		}
	} else {
		erase(tr[p].ch[x > tr[p].key], x);
	}
	if (p) push_up(p);
}

5. 排名与第 k 小

int get_rank(int p, int x) {
	if (!p) return 1;
	if (x < tr[p].key) return get_rank(tr[p].ch[0], x);
	if (x == tr[p].key) return tr[tr[p].ch[0]].sz + 1;
	return tr[tr[p].ch[0]].sz + tr[p].cnt + get_rank(tr[p].ch[1], x);
}

int get_kth(int p, int k) {
	int left = tr[tr[p].ch[0]].sz;
	if (k <= left) return get_kth(tr[p].ch[0], k);
	if (k <= left + tr[p].cnt) return tr[p].key;
	return get_kth(tr[p].ch[1], k - left - tr[p].cnt);
}

6. 前驱与后继

int predecessor(int p, int x) {
	int ans = -INF;
	while (p) {
		if (tr[p].key < x) ans = tr[p].key, p = tr[p].ch[1];
		else p = tr[p].ch[0];
	}
	return ans;
}

int successor(int p, int x) {
	int ans = INF;
	while (p) {
		if (tr[p].key > x) ans = tr[p].key, p = tr[p].ch[0];
		else p = tr[p].ch[1];
	}
	return ans;
}

7. AVL、Splay 与 set

  • AVL：严格维护左右子树高度差，查询稳定。
  • Splay：访问节点后把它伸展到根，支持区间翻转等拓展。
  • set：只能维护不同元素，能找前驱后继，但不能直接求排名和第 k 小。
  • multiset：允许重复，但仍不能直接求第 k 小。

8. FHQ Treap

FHQ Treap 不旋转，而是使用“分裂 + 合并”完成操作。

  • split(p,x,a,b)：把树 p 分成 key<=x 的 a 与 key>x 的 b。
  • merge(a,b)：要求 a 中所有键不大于 b，按随机优先级合并。
class FHQ {
private:
	struct node {
		int l, r, key, pri, sz;
	} tr[N];
	int root, tot;

	int size(int p) const { return p ? tr[p].sz : 0; }

	void pushup(int p) {
		tr[p].sz = size(tr[p].l) + size(tr[p].r) + 1;
	}

	int new_node(int x) {
		++tot;
		tr[tot].l = tr[tot].r = 0;
		tr[tot].key = x;
		tr[tot].pri = (int)rng();
		tr[tot].sz = 1;
		return tot;
	}

下面仍写在同一个 class FHQ 内，继续补充分裂和合并：


	void split(int p, int x, int &a, int &b) {
		if (!p) {
			a = b = 0;
			return;
		}
		if (tr[p].key <= x) {
			a = p;
			split(tr[p].r, x, tr[p].r, b);
			pushup(a);
		} else {
			b = p;
			split(tr[p].l, x, a, tr[p].l);
			pushup(b);
		}
	}

	int merge(int a, int b) {
		if (!a || !b) return a + b;
		if (tr[a].pri > tr[b].pri) {
			tr[a].r = merge(tr[a].r, b);
			pushup(a);
			return a;
		}
		tr[b].l = merge(a, tr[b].l);
		pushup(b);
		return b;
	}

最后接上同一个类的公开接口：


public:
	FHQ() : root(0), tot(0) {}

	void insert(int x) {
		int a, b;
		split(root, x, a, b);
		root = merge(merge(a, new_node(x)), b);
	}

	void erase(int x) {
		int a, b, c;
		split(root, x, a, c);
		split(a, x - 1, a, b);
		if (b) b = merge(tr[b].l, tr[b].r);
		root = merge(merge(a, b), c);
	}

	int rank(int x) {
		int a, b;
		split(root, x - 1, a, b);
		int ans = size(a) + 1;
		root = merge(a, b);
		return ans;
	}

	int kth(int k) const {
		int p = root;
		while (p) {
			int s = size(tr[p].l);
			if (k == s + 1) return tr[p].key;
			if (k <= s) p = tr[p].l;
			else k -= s + 1, p = tr[p].r;
		}
		return INF;
	}
};

FHQ Treap 容易扩展区间翻转、区间加法等隐式序列操作；此时按位置数量分裂，而不是按键值分裂。

第十一章 初等数论

1. gcd 与扩展 gcd

long long gcd(long long a, long long b) {
	return b ? gcd(b, a % b) : a;
}

long long exgcd(long long a, long long b, long long &x, long long &y) {
	if (!b) {
		x = 1; y = 0;
		return a;
	}
	long long x1, y1;
	long long g = exgcd(b, a % b, x1, y1);
	x = y1;
	y = x1 - a / b * y1;
	return g;
}

裴蜀定理：ax + by = c 有整数解，当且仅当 gcd(a,b) 整除 c。

2. 快速幂

long long qpow(long long a, long long b, long long mod) {
	long long ans = 1 % mod;
	while (b) {
		if (b & 1) ans = ans * a % mod;
		a = a * a % mod;
		b >>= 1;
	}
	return ans;
}

乘法可能超过 long long 时，需要使用安全乘法或 __int128；是否允许取决于比赛环境。

3. 模逆元

a 在模 p 下存在逆元，当且仅当 gcd(a,p)=1。

质数模：

a-1≡ ap-2(mod p)
long long inv(long long a, long long p) {
	return qpow(a, p - 2, p);
}

任意模数：用 exgcd 求 ax + py = 1 中的 x。

4. 线性筛

void get_prime(int n) {
	for (int i = 2; i <= n; i++) {
		if (!vis[i]) pri[++cnt] = i;
		for (int j = 1; j <= cnt && i * pri[j] <= n; j++) {
			vis[i * pri[j]] = true;
			if (i % pri[j] == 0) break;
		}
	}
}

每个合数只被最小质因子筛掉一次，复杂度 O(n)。

5. 欧拉函数

phi(n)：1..n 中与 n 互质的数的个数。

若：

n=p1a1p2a2… pkak

则：

φ(n)=n∏(1-1/pi)

单个数：

long long phi(long long n) {
	long long ans = n;
	for (long long p = 2; p * p <= n; p++) {
		if (n % p == 0) {
			ans = ans / p * (p - 1);
			while (n % p == 0) n /= p;
		}
	}
	if (n > 1) ans = ans / n * (n - 1);
	return ans;
}

6. 线性筛欧拉函数

void get_phi(int n) {
	phi_arr[1] = 1;
	for (int i = 2; i <= n; i++) {
		if (!vis[i]) pri[++cnt] = i, phi_arr[i] = i - 1;
		for (int j = 1; j <= cnt && i * pri[j] <= n; j++) {
			int p = pri[j];
			vis[i * p] = true;
			if (i % p == 0) {
				phi_arr[i * p] = phi_arr[i] * p;
				break;
			}
			phi_arr[i * p] = phi_arr[i] * (p - 1);
		}
	}
}

7. 中国剩余定理

互质模数：

x≡ ai(mod mi)
long long crt(int n) {
	long long M = 1, ans = 0;
	for (int i = 1; i <= n; i++) M *= m[i];
	for (int i = 1; i <= n; i++) {
		long long Mi = M / m[i];
		long long x, y;
		exgcd(Mi, m[i], x, y);
		x = (x % m[i] + m[i]) % m[i];
		ans = (ans + a[i] * Mi % M * x) % M;
	}
	return (ans + M) % M;
}

模数乘积可能溢出；非互质模数不能直接套此模板。

8. 组合数取模

fac[0] = 1;
for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % mod;
ifac[n] = qpow(fac[n], mod - 2, mod);
for (int i = n; i >= 1; i--) ifac[i - 1] = ifac[i] * i % mod;

long long C(int n, int k) {
	if (k < 0 || k > n) return 0;
	return fac[n] * ifac[k] % mod * ifac[n - k] % mod;
}

条件：mod 为质数，且阶乘在模意义下可逆。组合模型与容斥见《组合数学》课件。

9. 线性同余方程

求：

ax≡ b(mod m)

等价于 ax + my = b。令 g=gcd(a,m)：

  • b%g!=0：无解。
  • 否则先由扩展 gcd 得到一组解，再乘 b/g。
  • 模 m/g 意义下共有一个基本解类。
bool linear_mod(long long a, long long b, long long m, long long &x) {
	long long y;
	long long g = exgcd(a, m, x, y);
	if (b % g) return false;
	long long mod = m / g;
	x = (__int128)x * (b / g) % mod;
	if (x < 0) x += mod;
	return true;
}

10. 扩展中国剩余定理

逐个合并两个同余式：

x≡ a(mod m),    x≡ b(mod n)

令 x=a+mk，代入得到：

mk≡ b-a(mod n)

用线性同余求 k。若无解，整个方程组无解；新模数为 lcm(m,n)。

bool merge_crt(long long &a, long long &m, long long b, long long n) {
	long long x, y;
	long long g = exgcd(m, n, x, y);
	long long d = b - a;
	if (d % g) return false;
	long long t = n / g;
	x = (__int128)x * (d / g) % t;
	if (x < 0) x += t;
	a = a + (__int128)m * x;
	m = m / g * n;
	a %= m;
	if (a < 0) a += m;
	return true;
}

乘法中间值可能溢出，使用 __int128 仅作为 GNU C++ 环境下的实现选择。

11. Lucas 定理

当模数 p 为质数且 n 很大、p 较小时：

C(n,k)≡ C(n/p,k/p)C(nmod p,kmod p)(mod p)
long long lucas(long long n, long long k, int p) {
	if (k == 0) return 1;
	return C(n % p, k % p) * lucas(n / p, k / p, p) % p;
}

其中小组合数 C(a,b) 只处理 0<=a,b<p，可用阶乘逆元预处理。

1. 矩阵乘法

A 为 n x m，B 为 m x k，结果为 n x k：

Cij=∑t=1mAitBtj

矩阵乘法满足结合律，但通常不满足交换律。

node mul(const node &x, const node &y, long long mod) {
	node z;
	z.n = x.n; z.m = y.m;
	memset(z.a, 0, sizeof z.a);
	for (int i = 0; i < x.n; i++)
		for (int k = 0; k < x.m; k++)
			for (int j = 0; j < y.m; j++)

	return z;
}

2. 矩阵快速幂

node matrix_pow(node a, long long b, long long mod) {
	node ans;
	ans.n = ans.m = a.n;
	memset(ans.a, 0, sizeof ans.a);
	for (int i = 0; i < a.n; i++) ans.a[i][i] = 1;
	while (b) {
		if (b & 1) ans = mul(ans, a, mod);
		a = mul(a, a, mod);
		b >>= 1;
	}
	return ans;
}

3. 递推转移矩阵

Fibonacci 的矩阵关系：

│        │ = │      │ │        │

识别步骤：

  1. 把需要保留的连续状态排成向量。
  2. 根据递推式填写转移矩阵。
  3. 用矩阵快速幂跨越大量步数。

4. 高斯消元

int gauss(int n) {
	for (int c = 0, r = 0; c < n; c++) {
		int p = r;
		for (int i = r; i < n; i++)
			if (fabs(a[i][c]) > fabs(a[p][c])) p = i;
		if (fabs(a[p][c]) < eps) continue;
		for (int j = c; j <= n; j++) swap(a[p][j], a[r][j]);
		for (int j = n; j >= c; j--) a[r][j] /= a[r][c];
		for (int i = 0; i < n; i++) {
			if (i == r || fabs(a[i][c]) < eps) continue;
			double t = a[i][c];
			for (int j = n; j >= c; j--) a[i][j] -= t * a[r][j];
		}
		r++;
	}
	for (int i = 0; i < n; i++) {
		bool all_zero = true;
		for (int j = 0; j < n; j++)
			if (fabs(a[i][j]) >= eps) all_zero = false;
		if (all_zero && fabs(a[i][n]) >= eps) return 0;
	}
	return 1;
}

完整判断还需记录主元数量：

  • 主元数等于未知数数：唯一解。
  • 出现 0 = 非0：无解。
  • 无矛盾但主元不足：多解。

5. 易错点

  • 浮点比较使用 eps，不能直接 == 0。
  • 选绝对值最大的主元，减小误差。
  • 矩阵维度不匹配不能相乘。
  • 矩阵快速幂必须从单位矩阵开始。
  • 乘法三层循环中的维度顺序不能混乱。

6. 异或高斯消元

方程只含 0/1，加法改为异或，可使用 bitset 加速整行消元。

int gauss_xor(int n, int m) {
	int r = 0;
	for (int c = 0; c < m && r < n; c++) {
		int p = r;
		while (p < n && !a[p][c]) p++;
		if (p == n) continue;
		swap(a[p], a[r]);
		for (int i = 0; i < n; i++)
			if (i != r && a[i][c]) a[i] ^= a[r];
		r++;
	}
	for (int i = r; i < n; i++)
		if (a[i][m]) return -1;   // 无解
	return m - r;               // 自由变量数量
}

若返回自由变量数 k>=0，方案数通常为 2^k。矩阵每行需开到增广列 m。

3. 线段相交

bool segment_intersect(node a, node b, node c, node d) {

	double c2 = cross(b - a, d - a);
	double c3 = cross(d - c, a - c);
	double c4 = cross(d - c, b - c);
	if (sgn(c1) * sgn(c2) < 0 && sgn(c3) * sgn(c4) < 0) return true;
	if (on_segment(c, a, b) || on_segment(d, a, b)) return true;
	if (on_segment(a, c, d) || on_segment(b, c, d)) return true;
	return false;
}

7. 凸包

凸包是包含所有点的最小凸多边形。Andrew 算法先按 (x,y) 排序，再分别维护下凸壳和上凸壳。

bool cmp(const node &a, const node &b) {
	if (a.x != b.x) return a.x < b.x;
	return a.y < b.y;
}

vector<node> convex_hull(vector<node> p) {
	sort(p.begin(), p.end(), cmp);
	p.erase(unique(p.begin(), p.end(), [](const node &a, const node &b) {
		return a.x == b.x && a.y == b.y;
	}), p.end());
	if (p.size() <= 1) return p;

	vector<node> h;
	for (int i = 0; i < (int)p.size(); i++) {
		while (h.size() >= 2 &&
			cross(h.back() - h[h.size() - 2], p[i] - h.back()) <= 0)
			h.pop_back();
		h.push_back(p[i]);
	}
	int low = h.size();
	for (int i = (int)p.size() - 2; i >= 0; i--) {
		while ((int)h.size() > low &&
			cross(h.back() - h[h.size() - 2], p[i] - h.back()) <= 0)
			h.pop_back();
		h.push_back(p[i]);
	}
	h.pop_back();
	return h;
}

使用 <=0 会删除边上的共线中间点；改成 <0 会保留边界共线点。整数坐标建议把 node 改为 long long，避免浮点排序与去重问题。

8. 旋转卡壳入口

凸包直径是凸包上最远点对。暴力枚举为 O(h^2)，旋转卡壳利用对踵点单调移动降到 O(h)。使用前必须先求凸包，并处理点数 1、2 的情况。

2. 组合一：离散化 + 树状数组

例：动态统计逆序对

序列 8,3,6,2，从左向右加入，问新数与前面多少个数组成逆序对。

值域很大，但只关心大小关系。排序去重后：

原值 2 3 6 8
离散编号 1 2 3 4
加入值 编号 p 已加入数量 <=p 的数量 新增逆序对
8 4 0 0 0
3 2 1 0 1
6 3 2 1 1
2 1 3 0 3

答案为 5。

组合步骤

  1. 复制所有值，sort + unique。
  2. lower_bound 得到编号。
  3. 树状数组维护每个编号已经出现多少次。
  4. seen - sum(p) 得到前面比当前值大的数量。
vector<int> b(a + 1, a + n + 1);
sort(b.begin(), b.end());
b.erase(unique(b.begin(), b.end()), b.end());

long long ans = 0;
for (int i = 1; i <= n; i++) {
	int p = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;
	ans += (i - 1) - bit.sum(p);
	bit.add(p, 1);
}

同一组合还能解决：动态排名、二维偏序的一层、区间内小于某值的离线统计。

3. 组合二：离线排序 + 并查集

例：承重道路询问

每条边有承重 w。每个询问 (u,v,x) 问：只使用承重至少为 x 的道路，u、v 是否连通。

直接每次 DFS 是 O(q(V+E))。阈值越低，可用边只会增加，连通关系具有单调累积性。

小样例

边：1-2(9), 2-3(6), 3-4(3)。

当前询问阈值 已加入的边 询问 结果
8 1-2 1,3 不连通
5 再加 2-3 1,3 连通
2 再加 3-4 1,4 连通

实现骨架

struct node {
	int u, v, w, id;
};

sort(edge + 1, edge + m + 1, [](const node &a, const node &b) {
	return a.w > b.w;
});
sort(ask + 1, ask + q + 1, [](const node &a, const node &b) {
	return a.w > b.w;
});

int j = 1;
for (int i = 1; i <= q; i++) {
	while (j <= m && edge[j].w >= ask[i].w) {
		dsu.merge(edge[j].u, edge[j].v);
		j++;
	}
	ans[ask[i].id] = dsu.same(ask[i].u, ask[i].v);
}

若条件是边权 <=x，排序方向整体反过来。

4. 组合三：扫描线 + 线段树

例：矩形面积并

两个矩形可能重叠，求至少被一个矩形覆盖的总面积。

每个矩形 [x1,x2) × [y1,y2) 产生两个事件：

x y 区间 标记
x1 [y1,y2) +1，矩形进入
x2 [y1,y2) -1，矩形离开

处理相邻事件 x[i-1] -> x[i] 前，线段树中的 len[1] 是这一整条竖带的覆盖高度。

面积增加=len[1]×(xi-xi-1)

为什么要离散化 y

线段树维护的不是坐标点，而是相邻坐标形成的线段。若去重坐标为 ys[1..k]，叶子 l 表示真实区间 [ys[l],ys[l+1])。

核心维护

void pushup(int p, int l, int r) {
	if (tag[p] > 0) {
		len[p] = ys[r + 1] - ys[l];
	} else if (l == r) {
		len[p] = 0;
	} else {
		len[p] = len[p << 1] + len[p << 1 | 1];
	}
}

void change(int p, int l, int r, int ql, int qr, int v) {
	if (ql <= l && r <= qr) {
		tag[p] += v;
		pushup(p, l, r);
		return;
	}
	int m = (l + r) >> 1;
	if (ql <= m) change(p << 1, l, m, ql, qr, v);
	if (qr > m) change(p << 1 | 1, m + 1, r, ql, qr, v);
	pushup(p, l, r);
}

同一 x 的事件先统一结算上一段面积，再全部修改覆盖状态。面积使用 long long。

5. 组合四：SCC 缩点 + DAG DP

例：矿区采集

有向图每个点有矿石价值；允许沿有向边移动，同一点价值只能获得一次，求最大价值。

若图中存在环，环内各点可以互相到达，应看成一个整体。

样例：

  • 环 {1,2,3}，点权和 12。
  • 环 {4,5}，点权和 9。
  • 边 3->4，边 5->6，点 6 权值 7。

缩点后变成 A(12) -> B(9) -> C(7)，DAG DP 答案为 28。

组合步骤

  1. Tarjan 求 bel[u]。
  2. 每个 SCC 内点权求和。
  3. 原边跨 SCC 时建立缩点边并去重。
  4. 在 DAG 上按拓扑序转移。
dp[v] = max(dp[v], dp[u] + val[v]);

若题目限制起点或终点，只初始化合法起点，并只在合法终点中取答案。

6. 组合五：桥 + 边双缩点 + 树上算法

例：修复通信网络

连通无向图中，一条边故障可能使网络断开。问最少增加多少条边，使任意一条边故障后网络仍连通。

推导

  1. 桥是所有危险边。
  2. 忽略桥，把每个边双连通分量缩成点。
  3. 所有桥形成桥树。
  4. 树的叶子只有一条对外桥，必须与其他叶子配对补边。

若桥树叶子数为 leaf：

答案=(leaf+1)/2

例：桥树是一条 A-B-C-D 链，叶子是 A,D，补一条 A-D 后所有桥都进入环，答案为 1。

变形

  • 问两点之间有多少条必经边：桥树上距离。
  • 选择一条新边使剩余桥最少：在桥树直径两端加边，消去直径上的桥。
  • 多次问删边是否断开：先判断该边是否为桥，再判断两点位于桥树的哪一侧。

7. 组合六：二分图匹配 + 最小点覆盖

例：最少安排监考员

左部是考场，右部是时间段，一条边表示该考场在该时间段需要监考。选择尽量少的“考场负责人”或“时间负责人”，使每项需求至少被一个负责人覆盖。

这不是选边，而是选边的端点，因此模型是最小点覆盖。

  1. 建二分图。
  2. 求最大匹配。
  3. 根据 Kőnig 定理，最少人数等于最大匹配数。
  4. 若要输出方案，从未匹配左点沿交替路构造 (L-ZL)+ZR。

对比

题目问法 选择对象 模型
最多完成多少项一一配对 边 最大匹配
最少选择多少端点覆盖全部关系 点 最小点覆盖
最多选择多少互不冲突的点 点 最大独立集

先判断“答案选的是点还是边”，可以避免模型混淆。

8. 组合七：DFS 序 + 树状数组

例：子树加、单点查

对以 1 为根的树执行：

  • 给 u 的整棵子树加 x。
  • 查询点 v 当前值。

DFS 序使 u 的子树变成连续区间 [dfn[u],out[u]]。区间加、单点查可用差分树状数组：

void add_subtree(int u, long long x) {
	bit.add(dfn[u], x);
	bit.add(out[u] + 1, -x);
}

long long query_point(int u) {
	return base[u] + bit.sum(dfn[u]);
}

变形对应

树上操作 DFS 序后的数组操作
子树加、单点查 区间加、单点查
单点加、子树和 单点加、区间和
子树加、子树和 区间加、区间和，需要双树状数组或 lazy 线段树

路径操作不能直接变成一个 DFS 序区间，需要树链剖分或树上差分。

9. 组合八：LCA + 树上差分

例：统计每条边被多少条路径经过

对每条询问路径 (u,v)：

cnt[u]++;
cnt[v]++;
cnt[lca(u, v)] -= 2;

最后从叶子向根汇总：

void dfs_sum(int u, int fa) {
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (v == fa) continue;
		dfs_sum(v, u);
		cnt[u] += cnt[v];
		use[parent_edge[v]] = cnt[v];
	}
}

cnt[v] 表示父边 fa[v]-v 被经过多少次。

若统计点经过次数，差分改为：

cnt[u]++;
cnt[v]++;
cnt[lca]--;
if (fa[lca]) cnt[fa[lca]]--;

点差分与边差分公式不同，是高频错误。

10. 组合九：单调队列 + DP

例：限制跳跃距离的最小代价

到达位置 i 的代价为 cost[i]，每次可以从前面最多 k 个位置跳来：

dp[i]=cost[i]+min(dp[j]),    i-k≤ j<i

直接枚举 j 是 O(nk)。窗口向右移动时，只需维护候选 dp[j] 的最小值。

deque<int> q;
dp[0] = 0;
q.push_back(0);
for (int i = 1; i <= n; i++) {
	while (!q.empty() && q.front() < i - k) q.pop_front();
	dp[i] = dp[q.front()] + cost[i];
	while (!q.empty() && dp[q.back()] >= dp[i]) q.pop_back();
	q.push_back(i);
}

队首删除过期决策，队尾删除更差且更早过期的决策。若要求方案数，不能简单删除所有相等值，需要同时维护相等最优值的贡献。

11. 组合十：二分答案 + 贪心判定

例：最小化最大分组和

把正整数序列分成不超过 k 个连续段，最小化最大段和。

答案范围：

  • 下界：数组最大值。
  • 上界：数组总和。

固定最大允许和 x 后，从左向右尽量延长当前段，超过 x 就新开一段。x 越大，需要的段数不会增加，因此具有单调性。

bool check(long long x) {
	int cnt = 1;
	long long sum = 0;
	for (int i = 1; i <= n; i++) {
		if (a[i] > x) return false;
		if (sum + a[i] > x) cnt++, sum = a[i];
		else sum += a[i];
	}
	return cnt <= k;
}

手工模拟 check 时必须列出每次“继续当前段”还是“切段”，否则二分边界正确也可能因判定函数错误而失败。

12. 组合十一：最短路 + 最短路 DAG DP

例：最短路径条数

先用 Dijkstra 求 dist。一条有向边 u->v 属于最短路结构，当且仅当：

dist[u]+w(u,v)=dist[v]

若边权严格为正，距离沿这些边严格增加，形成 DAG。按 dist 从小到大转移方案数：

sort(id + 1, id + n + 1, [](int x, int y) {
	return dist[x] < dist[y];
});

ways[s] = 1;
for (int k = 1; k <= n; k++) {
	int u = id[k];
	for (int i = head[u]; i; i = e[i].nxt) {
		int v = e[i].to;
		if (dist[u] + e[i].w == dist[v])
			ways[v] = (ways[v] + ways[u]) % mod;
	}
}

存在零权边时，同距离点之间可能形成环，不能直接按距离当拓扑序；需要进一步缩点或单独处理零权最短路子图。

必经点信号

同时统计从起点到 u 的最短路条数 f[u]，以及从 u 到终点的最短路条数 g[u]。若：

f[u]× g[u]=f[t]

则所有最短路都经过 u。计数很大时可使用双模哈希降低碰撞风险，或改用最短路 DAG 上的支配关系。

13. 组合十二：数位 DP + KMP 自动机

例：统计不含模式 13 的整数

普通数位 DP 状态有 pos、limit、lead。为了判断当前数字串是否已经出现禁用模式，再加入 KMP 状态 j，表示当前后缀与模式前缀匹配的长度。

long long dfs(int pos, int j, bool limit, bool lead) {
	if (j == m) return 0;              // 已出现禁用模式
	if (pos < 0) return 1;
	if (!limit && !lead && vis[pos][j]) return memo[pos][j];

	int up = limit ? dig[pos] : 9;
	long long ans = 0;
	for (int d = 0; d <= up; d++) {
		bool nl = lead && d == 0;
		int nj = nl ? 0 : go[j][d];
		ans += dfs(pos - 1, nj, limit && d == up, nl);
	}
	if (!limit && !lead) vis[pos][j] = true, memo[pos][j] = ans;
	return ans;
}

先由 KMP 失配函数预处理自动机转移 go[j][d]。这类组合的本质是“DP 需要记住会影响未来合法性的最短历史”。

14. 组合十三：状态压缩 + 最短路

例：钥匙开门迷宫

位置相同但持有钥匙集合不同，后续可走的门不同，因此状态必须是 (位置, mask)。

struct node {
	int u, mask, dis;
};

queue<node> q;
q.push(node{s, 0, 0});
vis[s][0] = true;

while (!q.empty()) {
	node t = q.front();
	q.pop();
	for (每条可走边 t.u -> v) {
		if (门需要的钥匙不在 t.mask 中) continue;
		int nm = t.mask | key[v];
		if (!vis[v][nm]) {
			vis[v][nm] = true;
			q.push(node{v, nm, t.dis + 1});
		}
	}
}

状态数为 位置数 × 2^钥匙数。若边权不是 1，把 BFS 换成 Dijkstra，状态定义不变。

15. 综合题拆解示例

题意：有向城市图，每个城市有收益；可以选择一条起点到终点的路线，环内收益只计算一次；另外有若干条候选道路，只能选择不冲突的工队修建，问最大收益和最大可修道路数。

拆解：

  1. “有向环内可往返”提示 SCC。
  2. “收益只计算一次”提示 SCC 内点权求和。
  3. 缩点后是 DAG，起点到终点最大收益用 DAG DP。
  4. “工队与道路一一分配、存在可选关系”单独建二分图。
  5. 最大可修道路数用二分图最大匹配。
  6. 两部分答案没有状态依赖，应分别计算后输出，不要强行合并 DP 状态。

综合题并不意味着所有算法必须写进同一个循环。先判断模块之间是串联、并联还是互相作为状态。

18. 交卷前组合检查

  1. 前一个模块的编号是否从原图切换成缩点编号或离散编号？
  2. 新图是否需要去重边、重新统计入度？
  3. 树状数组、线段树维护的是点还是相邻坐标段？
  4. 公式的适用前提是否成立，例如二分图、DAG、正边权？
  5. 串联模块的复杂度相加后是否仍能通过？
  6. 多测时每个模块的数组是否都清空？
  7. 输出方案时是否保留了前驱、匹配或缩点映射？
  8. 对拍程序是否覆盖模块接口处的边界？
