使用说明与目录

本手册用于做题时快速翻阅，不代替专题课件。内容按“能判断、能回忆、能落笔”压缩：保留核心概念、公式、模板、选择依据和易错点，省略长篇例题与推导。

收录“集训资料课件”中的 25 篇知识专题；不收录《思维》《组合数学》《数据结构理论》，三者继续作为独立课件使用。

使用约定

  • 数组默认使用 1 下标；字符串和 STL 容器默认使用 0 下标。
  • n、m 表示规模，i、j、k 表示下标，l、r 表示左右边界。
  • cnt 表示数量，sum 表示总和，ans 表示答案，INF 表示无穷大。
  • 结构体名称统一使用 node；大整数优先使用 long long。
  • 模板只展示核心部分，数组大小、输入输出和初始化必须按题目调整。

阅读任何模板时先确认“四项语义”：

第一章 运算符

1. 算术运算

运算 写法 重点
加减乘 + - * 乘积可能溢出
整除 a / b 两个整数相除舍去小数；b != 0
取模 a % b 两边必须是整数；常用于余数、周期、数位
自增自减 i++ i-- 初学阶段单独成行 
double avg = 1.0 * sum / n;  // 避免整数除法
long long x = 1LL * a * b;   // 先转 long long 再乘

精确定义：

  • 两个整数做 /，结果向 0 截断：7/3==2，-7/3==-2。
  • C++ 始终满足 a == (a/b)*b + a%b；负数取模的结果可能为负。
  • 需要数学意义的非负余数时可写 ((a%mod)+mod)%mod，其中 mod>0。
  • 前置 ++i 是“先加再取值”，后置 i++ 是“先取旧值再加”；作为独立语句时最终效果相同。
int a = 5;
int x = ++a;  // a=6，x=6
int y = a++;  // y=6，之后 a=7

不要在一个复杂表达式中多次修改同一变量，竞赛代码优先把 i++ 单独成行。

2. 关系与逻辑

含义 写法
相等 / 不等 == / !=
大小比较 < <= > >=
并且 / 或者 / 非 && / || / !
闭区间内 l <= x && x <= r
闭区间外 x < l || x > r

短路：A && B 中 A 为假时不算 B；A || B 中 A 为真时不算 B。可用于先判边界再访问数组。

if (i <= n && a[i] == x) {}  // 先保证 i 合法，再访问 a[i]

逻辑语义：数值 0 转为假，非 0 转为真；逻辑表达式结果是 bool。不要写数学式 0 <= x <= 10，C++ 会先算 0<=x 得到 0/1，再拿它与 10 比较；正确写法是 0<=x && x<=10。

3. 复合运算与优先级

sum += x;  // sum = sum + x
x %= mod;

常用优先级：() > 一元 ! > * / % > + - > 关系 > == != > && > || > 赋值。

条件运算符适合简单二选一：

int mx = (a > b ? a : b);

它是“产生一个值的表达式”，不是替代所有 if 的写法；分支有多条语句时使用 if 更清楚。

易错： 判断相等写成 ==；不要写 sum =+ x；不确定优先级就加括号。

第二章 变量与常量

1. 类型与范围

类型 常见范围 / 用途 输入输出
bool false/true 0/1
char 单个字符 %c
int 约 -2.1e9 到 2.1e9 %d
long long 约 -9e18 到 9e18 %lld
double 小数，约 15 位有效数字 输入 %lf，输出 %f
string 字符串 cin/cout

声明、初始化、赋值含义不同：

int a;       // 声明局部变量，值未确定
int b = 0;   // 声明并初始化
b = 5;       // 给已存在的变量赋值
const int c = 10; // 常量必须初始化，之后不能改

全局变量和 static 变量默认初始化为 0；普通局部变量不会自动清零，读取未初始化值是错误行为。

字符与字符串不能混用：'A' 是一个 char，"A" 是字符串；'0' 的编码值不是整数 0，数字字符转数值要减 '0'。

const int N = 100010;
const double PI = 3.1415926;

常用字面量：1LL 强制后续整数运算使用 long long；1.0 强制浮点除法。1e9、1e18 是浮点字面量，不要依靠它们精确表示超大整数常量。

2. 类型转换

double x = (double)a / b;
double y = 1.0 * a / b;
long long z = 1LL * a * b;
int c = int(x);              // 截断小数，不是四舍五入

错误：(double)(a / b) 已经先完成整数除法。

赋值目标是 long long 也不能挽救已经发生的 int 溢出：

long long wrong = a * b;       // a*b 先按 int 计算
long long right = 1LL * a * b; // 先提升类型

从 double 转 int 会向 0 截断；大类型转小类型可能丢失数据；浮点比较通常写 fabs(a-b)<eps。

3. 格式化输出

printf("%d %lld %.2f\n", a, b, x);
cout << fixed << setprecision(2) << x << "\n";

格式化输入：

int a;
long long b;
double x;
scanf("%d%lld%lf", &a, &b, &x);

scanf 需要变量地址；double 输入是 %lf，printf 输出是 %f。使用快速 cin/cout 后，不建议再与 scanf/printf 混用。

易错： 先估算最大值；总和、乘积、方案数常用 long long；浮点数不要直接用 == 判断相等。

第三章 分支

1. 基本写法

if (x > 0) {
    cout << "positive";
} else if (x == 0) {
    cout << "zero";
} else {
    cout << "negative";
}

多分支从上到下执行第一个成立的分支；条件应互斥、完整，特殊情况通常先判断。

独立 if 与 else if 语义不同：

if (x >= 60) cnt++;  // 两个条件都会分别判断
if (x >= 90) good++;

if (x >= 90) grade = 'A';      // 只进入一个分支
else if (x >= 60) grade = 'B';
else grade = 'C';

else 与最近的、尚未匹配的 if 配对。始终写 {} 可以避免“悬空 else”歧义。

2. switch

switch (op) {
case '+': ans = a + b; break;
case '-': ans = a - b; break;
default: cout << "error";
}

适合固定离散值，不适合区间；忘记 break 会继续执行后续 case。

switch 常用于整数、字符和枚举值；case 标签必须是编译期常量，不能直接写范围或字符串。故意贯穿多个 case 时应加注释说明。

3. 分段模型

先写区间，再写每段公式。注意边界归属和“超出部分”只算超过量。

if (x <= a) ans = f1;
else if (x <= b) ans = f2;
else ans = f3;

易错： if (...) 后不要误加分号；多条语句加 {}；分段计费测试 a-1,a,a+1,b-1,b,b+1。

第四章 循环

1. 三要素与常用变量

for (int i = 1; i <= n; i++) {
    sum += i;
}
变量 初值 更新
计数 cnt 0 条件成立时 cnt++
累加 sum 0 sum += x
连乘 ans 1 ans *= x
最大值 mx 极小值 mx=max(mx,x)
最小值 mn 极大值 mn=min(mn,x)

break 结束整个循环；continue 只跳过本轮剩余语句。

三种循环：

for (int i = 1; i <= n; i++) {} // 次数或范围明确
while (x > 0) { x /= 10; }      // 是否继续由状态决定
do { cin >> x; } while (x < 0); // 循环体至少执行一次

break/continue 只影响它所在的最内层循环。嵌套循环复杂度通常是各层次数相乘，但双指针的内层指针若不回退，总移动次数仍可能是 O(n)。

区间语义要先确定：处理 1..n 写 i<=n；处理 0..n-1 写 i<n。不要凭习惯混用。

2. 幂、阶乘、因数与倍数

long long p = 1;
for (int i = 1; i <= b; i++) p *= a;       // a^b

long long fac = 1;
for (int i = 1; i <= n; i++) fac *= i;     // n!

for (int i = 1; i * i <= n; i++) {         // 枚举因数到 sqrt(n)
    if (n % i == 0) {
        int x = i, y = n / i;
    }
}

lcm(a,b)=a/gcd(a,b)*b，先除后乘降低溢出风险。

3. 数位分离

int old = x, rev = 0, sum = 0, cnt = 0;
do {
    int d = x % 10;          // 取当前个位
    sum += d;
    rev = rev * 10 + d;      // 构造反转数
    cnt++;
    x /= 10;                 // 删除当前个位
} while (x > 0);
bool is_pal = (old == rev);

常见用途：位数、数位和/积、最大/最小数位、统计某数字、反转、回文、自幂数。数字 0 有一位，需用 do...while 或特判。

“一字型、山形、梯形回文”是帮助观察数字外形的课堂分类，不是 C++ 或算法中的正式类型。程序判断仍应转化为精确条件：整体是否正反相同、某一段是否回文、左右数位是否按指定规律变化。

4. 图形输出

外层管行，内层管列；先算空格，再算符号。

图形 第 i 行空格 第 i 行符号
左直角三角形 0 i
右直角三角形 n-i i
正三角形 n-i 2*i-1
倒三角形 i-1 2*(n-i)+1
空心图形 同外形 只输出边界位置
X 形 无固定区块 j==i || j==n-i+1

右对齐图形先输出空格，再输出符号：

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n - i; j++) cout << ' ';  // 左侧空白区
    for (int j = 1; j <= i; j++) cout << '*';      // 右侧符号区
    cout << '\n';                                  // 一行结束
}

空心图形不是“少循环”，而是遍历整个外接矩形，只在边界输出符号。例如空心正方形的边界条件是 i==1 || i==n || j==1 || j==n，其余位置输出空格。

易错： 循环起点、终点、更新缺一不可；阶乘和幂增长快；图形每行末尾换行。

第五章 数组

1. 基础与增删改查

int a[N], n;

N 是容量，n 是当前有效元素个数，两者不能混用。int a[10] 的合法下标是 0..9；越界访问不会自动报错，但行为未定义。

局部数组默认未初始化；全局数组默认全 0。普通 C 数组不能直接写 b=a 完成整体复制，可用循环、copy(a,a+n,b) 或改用 vector。

操作 核心 复杂度
尾部增加 a[++n]=x O(1)
中间插入 从 n 到 pos 右移，再赋值，n++ O(n)
删除 从 pos 到 n-1 左移，n-- O(n)
修改 a[pos]=x O(1)
顺序查找 从头比较，未找到返回 -1 O(n) 
for (int i = n; i >= pos; i--) a[i + 1] = a[i];
a[pos] = x;
n++;

for (int i = pos; i < n; i++) a[i] = a[i + 1];
n--;

这里约定插入前有效位置为 1..n，插入位置允许 1..n+1；删除位置必须在 1..n。中间增删时移动方向不能反：插入从后向前，删除从前向后。

2. 连续性与周期性

  • 连续段：只比较相邻元素；关系断开时更新答案并重置当前长度。
  • 周期：若周期长为 k，常比较 a[i] 与 a[i-k]，或使用 a[i%k]。

连续子数组要求原下标相邻；子序列只要求保持先后顺序，可以跳过元素。周期还要区分“整个序列由周期完整重复”和“从某处开始呈周期”。

int len = 1, ans = 1;
for (int i = 2; i <= n; i++) {
    if (a[i] == a[i - 1]) len++;
    else len = 1;
    ans = max(ans, len);
}

3. 基础二分

前提：数组有序。

int l = 1, r = n;
while (l <= r) {
    int m = l + (r - l) / 2;
    if (a[m] == x) { ans = m; break; }
    if (a[m] < x) l = m + 1;
    else r = m - 1;
}

4. 二维数组与数字方阵

位置 条件（n*n 方阵，1 下标）
主对角线 i==j
副对角线 i+j==n+1
主对角线上 / 下 i<j / i>j
四条边 i==1 || i==n || j==1 || j==n
第 k 圈 min(min(i,j),min(n-i+1,n-j+1))==k
棋盘染色 (i+j)%2
到主对角线距离 abs(i-j)
到副对角线距离 abs(i+j-n-1)

二维数组 a[i][j] 中 i 表示行、j 表示列；内存按行连续存储。遍历通常外层行、内层列，交换两层会改变访问顺序但不改变访问总量。

螺旋方阵采用“方向数组 + 碰壁右转”。下一个位置越界或已经填过，就令方向编号 k=(k+1)%4：

int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};
int x = 1, y = 1, k = 0;
for (int v = 1; v <= n * n; v++) {
    a[x][y] = v;                         // 填入当前格
    int nx = x + dx[k], ny = y + dy[k];
    if (nx < 1 || nx > n || ny < 1 || ny > n || a[nx][ny] != 0) {
        k = (k + 1) % 4;                 // 前方不可走，顺时针转向
        nx = x + dx[k], ny = y + dy[k];
    }
    x = nx, y = ny;
}

int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};
for (int k = 0; k < 4; k++) {

2. 基础排序记忆

  • 冒泡排序：相邻逆序就交换，每轮把最大值送到右端；交换次数等于逆序对数。
  • 选择排序：每轮找最小值放到当前位置。
  • 插入排序：取出当前值，把前面较大的值右移，再插入。
  • 计数排序：统计每个值出现次数，再按值从小到大还原；适合值域小的整数。
  • 基数排序：从低位到高位按位稳定分配和收集；只适合可按位拆分的键。
  • 快速排序：先选基准并分区，再递归处理两侧。
  • 归并排序：先递归排好左右两段，再双指针合并。

void quick_sort(int l, int r) {
    if (l >= r) return;
    int x = a[(l + r) >> 1];
    int i = l - 1, j = r + 1;
    while (i < j) {
        do i++; while (a[i] < x);
        do j--; while (a[j] > x);
        if (i < j) swap(a[i], a[j]);
    }
    quick_sort(l, j);
    quick_sort(j + 1, r);
}

归并排序：

int tmp[N];

void merge_sort(int l, int r) {
    if (l >= r) return;
    int m = (l + r) >> 1;
    merge_sort(l, m);
    merge_sort(m + 1, r);
    int i = l, j = m + 1, k = 0;
    while (i <= m && j <= r)
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = 0; t < k; t++) a[l + t] = tmp[t];
}

2. 数组模拟单链表

    e[idx] = x;
    ne[idx] = head;
    head = idx++;
}

    e[idx] = x;
    ne[idx] = ne[k];
    ne[k] = idx++;
}

    ne[k] = ne[ne[k]];
}

x->next = q;
p->next = x;
q->pre = x;

x->next->pre = x->pre;

第十四章 前缀和与差分

1. 一维

一维前缀和

操作 公式
前缀构造 s[i]=s[i-1]+a[i]
区间和 [l,r] s[r]-s[l-1]
差分构造 d[i]=a[i]-a[i-1]
区间加 x d[l]+=x, d[r+1]-=x
差分还原 a[i]=a[i-1]+d[i] 
for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];
long long sum = s[r] - s[l - 1];

一维差分

完整写法：

for (int i = 1; i <= n; i++) d[i] = a[i] - a[i - 1];

void add_range(int l, int r, int x) {
    d[l] += x;
    d[r + 1] -= x;
}

for (int i = 1; i <= n; i++) {
    a[i] = a[i - 1] + d[i];
}

2. 二维

二维前缀和

构造：

s[i][j]=s[i-1][j]+s[i][j-1]-s[i-1][j-1]+a[i][j]

子矩形 (x1,y1) 到 (x2,y2)：

s[x2][y2]-s[x1-1][y2]-s[x2][y1-1]+s[x1-1][y1-1]

二维差分

对子矩形加 x，四角符号 + - - +：

d[x1][y1] += x;
d[x2 + 1][y1] -= x;
d[x1][y2 + 1] -= x;
d[x2 + 1][y2 + 1] += x;

二维前缀和构造与查询：

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        s[i][j] = s[i - 1][j] + s[i][j - 1]
                - s[i - 1][j - 1] + a[i][j];

long long query(int x1, int y1, int x2, int y2) {
    return s[x2][y2] - s[x1 - 1][y2]
         - s[x2][y1 - 1] + s[x1 - 1][y1 - 1];
}

二维差分还原使用同样的二维前缀累积公式；数组需额外开出第 n+1 行与第 m+1 列。

选择： 多次静态查询用前缀和；多次修改、最后查询用差分；修改查询交替用树状数组或线段树。

第十五章 位运算

1. 基础操作

操作 性质
& 与 两位都为 1 才为 1；保留位
| 或 有一位为 1 就为 1；设置位
^ 异或 不同为 1；相同抵消
~ 取反 每一位翻转
<< k 非溢出时乘 2^k
>> k 非负整数相当于除 2^k

2. 位操作公式

目标 写法

构造 2^k 1LL << k

3. 状态压缩

第 i 位表示第 i 个对象是否选择：

for (int s = 0; s < (1 << n); s++) {
    for (int i = 0; i < n; i++) {
        if ((s >> i) & 1) {
            // 第 i 个对象被选择
        }
    }
}

枚举非空子集：

for (int sub = s; sub; sub = (sub - 1) & s) {}

编译器常用函数：

int c1 = __builtin_popcount(x);       // unsigned int 中 1 的个数
int c2 = __builtin_popcountll(x);     // unsigned long long
int z1 = __builtin_ctz(x);            // 末尾 0 的个数，要求 x!=0
int z2 = __builtin_clz(x);            // 前导 0 的个数，要求 x!=0

异或查找只出现一次的数：若其他数都恰好出现两次，全部异或后的结果就是唯一数。

易错： 位编号从 0 开始；移位较大时使用 1LL；复杂表达式加括号；初学阶段优先处理非负整数。

4. bitset

bitset<N> 是长度固定的二进制位集合，N 必须是编译期常量。它把许多真假状态压在若干机器字中，批量位运算通常比逐位循环快。

操作 写法 含义
访问 b[i] 第 i 位，编号从 0 开始
设为 1 b.set(i) 不传位置时全部设为 1
设为 0 b.reset(i) 不传位置时全部清零
翻转 b.flip(i) 不传位置时全部翻转
统计 b.count() 1 的数量
判断 b.any() / b.none() / b.all() 是否有 1、全 0、全 1
转换 b.to_string() 得到由 0 和 1 组成的字符串
整体运算 &、|、^、~、<<、>> 对全部位并行操作 
const int M = 1000;
bitset<M + 1> f;
f[0] = 1;
for (int i = 1; i <= n; i++) {
    f |= (f << a[i]);  // 01 选数：原有和与加上 a[i] 后的和
}
if (f[x]) cout << "YES";

构造示例：bitset<8> a(13) 得到 00001101；bitset<8> b("10110010") 从字符串读取。bitset 不能动态改变长度；转换为整数时若高位超出目标类型范围会抛出异常。

void dfs(int u) {
    if (u > n) {
        // 使用 path[1..n]
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;
        used[i] = true;
        path[u] = i;
        dfs(u + 1);
        used[i] = false;

3. 剪枝

剪枝 含义
可行性剪枝 当前已违反限制，立即返回
最优性剪枝 当前代价已不可能更优
上下界剪枝 剩余最好情况也达不到目标
去重剪枝 同层相同选择只尝试一次
顺序优化 先尝试更可能成功的选择

暴力先写对，再剪枝；剪枝只能删除确定不可能产生答案的分支。

4. 组合与子集 DFS 模板

从 1..n 选择 m 个数：

int path[N];

void dfs(int start, int u) {
    if (u > m) {
        // 使用 path[1..m]
        return;
    }
    if (n - start + 1 < m - u + 1) return; // 剩余数量不足
    for (int x = start; x <= n; x++) {
        path[u] = x;
        dfs(x + 1, u + 1);
    }
}

每个元素选或不选：

void dfs(int u) {
    if (u > n) {
        // 使用当前子集
        return;
    }
    dfs(u + 1);          // 不选 u
    chosen.push_back(u);
    dfs(u + 1);          // 选择 u
    chosen.pop_back();
}

1. 模拟方法

2. 高精度存储

  • 加、减、乘低精：通常倒序存位，最低位在下标 0。
  • 除低精：从最高位到最低位扫描，维护余数。
  • 减法先比较大小；输出前删除多余前导零。

加法核心：

for (int i = 0, t = 0; i < a.size() || i < b.size() || t; i++) {
    if (i < a.size()) t += a[i];
    if (i < b.size()) t += b[i];
    c.push_back(t % 10);
    t /= 10;
}

减法核心（保证 a>=b）：

for (int i = 0, t = 0; i < a.size(); i++) {
    t = a[i] - t - (i < b.size() ? b[i] : 0);
    c.push_back((t + 10) % 10);
    t = (t < 0);
}
while (c.size() > 1 && c.back() == 0) c.pop_back();

乘低精核心：

for (int i = 0, t = 0; i < a.size() || t; i++) {
    if (i < a.size()) t += a[i] * b;
    c.push_back(t % 10);
    t /= 10;
}

除低精核心（a 正序字符串）：

long long r = 0;
for (char ch : a) {
    r = r * 10 + (ch - '0');
    c.push_back(char(r / b + '0'));
    r %= b;
}

易错： 操作顺序不能擅自交换；容器访问前判空；地图先判界再访问；高精度处理最后进位、借位、前导零和正负号。

第十八章 二分

1. 使用前提

  • 普通二分：查找范围有序。
  • 边界二分：真假分界单调，例如 FFFFTTTT 或 TTTTFFFF。
  • 二分答案：check(x) 随 x 单调变化，且答案范围可确定。

2. 闭区间模板

精确查找：

int binary_find(const int a[], int n, int x) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (a[m] == x) return m;
        if (a[m] < x) l = m + 1;
        else r = m - 1;
    }
    return -1;
}

精确查找只保证返回某一个等于 x 的位置，不保证第一个或最后一个；有重复值时应使用边界二分。

第一个 >=x：

int l = 1, r = n, ans = n + 1;
while (l <= r) {
    int m = l + (r - l) / 2;
    if (a[m] >= x) ans = m, r = m - 1;
    else l = m + 1;
}

最后一个 <=x：

int l = 1, r = n, ans = 0;
while (l <= r) {
    int m = l + (r - l) / 2;
    if (a[m] <= x) ans = m, l = m + 1;
    else r = m - 1;
}

由此可改出：第一个 >x、最后一个 <x、第一个/最后一个 ==x。

3. STL 边界

int p1 = lower_bound(a + 1, a + n + 1, x) - a; // 第一个 >= x
int p2 = upper_bound(a + 1, a + n + 1, x) - a; // 第一个 > x
int cnt = p2 - p1;                              // x 的个数

lower_bound 和 upper_bound 返回迭代器；可能等于尾后位置。

4. 二分答案

最小可行：

long long l = low, r = high, ans = high;
while (l <= r) {
    long long m = l + (r - l) / 2;
    if (check(m)) ans = m, r = m - 1;
    else l = m + 1;
}

最大可行：check(m) 成立后记录并令 l=m+1。

写 check 前必须明确：

mid 代表什么？
怎样用样例逐步模拟 mid？
check(mid)=true 表示可行还是不可行？
true 后答案在左边还是右边？
为什么可行性单调？

常见上下界：最大单项、总和、坐标差、答案理论极值。

5. 实数二分

double l = low, r = high;

第十九章 贪心

1. 核心判断

贪心每一步选择当前最优，但必须证明它不会破坏全局最优。常用证明：交换论证、领先法、下界达到、数学归纳法。样例只能提出策略，不能证明策略。

交换论证：设最优解没选贪心选择 g，找到对应选择 x，证明把 x 换成 g 后仍合法且不变差，因此存在包含 g 的最优解。

2. 区间类

问题 排序 选择规则
最多互不重叠区间 右端点升序 选当前最早结束且不冲突的区间
最少区间覆盖 [L,R] 左端点升序 在起点 <=L 中选右端最远，更新 L
最少点覆盖所有区间 右端点升序 取当前区间右端点，跳过已覆盖区间

端点是否允许相等由题目决定，例如闭区间不重叠通常要求 next.l > last.r。

区间调度：

sort(a + 1, a + n + 1, [](const node &x, const node &y) {
    return x.r < y.r;
});
int cnt = 0, last = -INF;
for (int i = 1; i <= n; i++) {
    if (a[i].l >= last) { // 按题意决定 >= 还是 >
        cnt++;
        last = a[i].r;
    }
}

区间选点：

sort(a + 1, a + n + 1, [](const node &x, const node &y) {
    return x.r < y.r;
});
int cnt = 0, point = -INF;
for (int i = 1; i <= n; i++) {
    if (point < a[i].l) {
        point = a[i].r;
        cnt++;
    }
}

区间覆盖 [L,R]：

sort(a + 1, a + n + 1, [](const node &x, const node &y) {
    if (x.l != y.l) return x.l < y.l;
    return x.r > y.r;
});
int i = 1, cnt = 0;
while (L < R) {
    int far = L;
    while (i <= n && a[i].l <= L) far = max(far, a[i++].r);
    if (far == L) { cnt = -1; break; } // 无法继续覆盖
    L = far;
    cnt++;
}

3. 背包、合并与分配

模型 策略 工具

哈夫曼合并 每次合并最小两项 小根堆
多窗口分配 分给当前总负载最小窗口 小根堆
取 k 个最大/最小 排序后取前/后 k 个 排序/堆
排队取水 短任务在前 按耗时升序

分数背包可分割才能贪心；01 背包不可直接按单位价值贪心。

sort(a + 1, a + n + 1, [](const node &x, const node &y) {
    return 1.0 * x.v / x.w > 1.0 * y.v / y.w;
});
double ans = 0, cap = m;
for (int i = 1; i <= n && cap > 0; i++) {
    double take = min(cap, 1.0 * a[i].w);
    ans += take * a[i].v / a[i].w;

}

Kadane：

5. 调度模型

  • 有截止时间且求最大收益：按时间排序，使用堆保留当前更优集合。
  • 两机流水作业 Johnson：a[i]<b[i] 的任务放前面按 a 升序；其余放后面按 b 降序。
  • 加油/覆盖类问题：在当前可达范围内选择能把下一阶段推进最远或代价最优的对象；具体策略必须结合题目证明。

6. 反悔贪心

先接受当前方案；若超出限制，删除已选集合中最差的一项。堆保存“最容易被反悔”的对象。

经典：在截止时间前完成最多任务，按截止时间升序，先加入任务耗时；若总耗时超过当前截止时间，删掉耗时最长的任务。

sort(a + 1, a + n + 1, cmp_deadline);
priority_queue<int> q;
long long sum = 0;
for (int i = 1; i <= n; i++) {
    sum += a[i].t;
    q.push(a[i].t);
    if (sum > a[i].d) {
        sum -= q.top();
        q.pop();
    }
}

易错： 排序规则与策略不一致；堆方向反了；反悔后未同步答案；局部最优没有证明；区间边界 < 与 <= 混淆。

第二十章 双指针与多指针

1. 为什么能优化

暴力会让端点反复回头；双指针利用有序性或窗口单调性，让每个指针最多走 n 步，总移动次数为 O(n)，而不是把两个循环简单相乘。

成立关键：指针移动后，被跳过的状态不可能再成为答案。

2. 指针数量与移动关系

数量 说明
双指针 两个位置共同描述区间、配对或扫描进度
三指针 固定一个位置，另两个对撞；或维护三段边界
多指针 多个有序序列各自维护当前位置
移动类型 典型用途
对撞 有序数组两数和、回文判断
同向 滑动窗口、去重、分段
快慢 删除元素、链表判环、找中点
分离 两个不同数组匹配
归并 合并两个有序序列

3. 对撞指针

int l = 1, r = n;
while (l < r) {
    long long s = a[l] + a[r];
    if (s == target) break;
    if (s < target) l++;
    else r--;
}

前提通常是有序；移动依据必须保证另一侧不可能产生答案。

4. 滑动窗口

右端加入，窗口不合法时左端持续移出：

int l = 1;
for (int r = 1; r <= n; r++) {
    add(a[r]);
    while (!valid()) {
        remove(a[l]);
        l++;
    }
    ans = max(ans, r - l + 1);
}

常见维护：窗口和、不同元素数、字符频次、最大最小值。若负数导致窗口和不再单调，普通滑窗可能失效。

5. 快慢指针

原地保留合法元素：

int slow = 0;
for (int fast = 1; fast <= n; fast++) {
    if (ok(a[fast])) a[++slow] = a[fast];
}

Floyd 判环：慢指针一步、快指针两步；相遇说明有环。相遇后一个指针回到起点，两者每次一步，再次相遇处是环入口。

6. 分离、归并与三指针

int i = 1, j = 1;
while (i <= n && j <= m) {
    if (a[i] < b[j]) i++;
    else if (a[i] > b[j]) j++;
    else { /* 匹配 */ i++; j++; }
}

三数之和：排序后枚举第一个位置 i，对后缀使用 l/r 对撞，复杂度由 O(n^3) 降为 O(n^2)；注意跳过重复值。

易错： 加入和移出操作不成对；指针没有单向移动；循环边界不匹配；和用 int 溢出；未经排序就套对撞模板。

第二十一章 搜索

1. 两个分类角度

按方法：DFS、BFS、0-1 BFS、优先队列搜索、双向 BFS。

按问题：方案枚举、连通性、最少步数、最短路径、最小成本、状态可达性。先判断任务类型，再选择方法。

2. 地图与状态

int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

状态不仅是坐标。方向、钥匙集合、剩余体力、已选对象等只要影响未来选择，就必须进入状态。

3. DFS 与回溯

void dfs(int x, int y) {
    vis[x][y] = true;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (inside(nx, ny) && !vis[nx][ny] && g[nx][ny] != '#') {
            dfs(nx, ny);
        }
    }
}

回溯顺序：选择 -> 修改状态 -> 递归 -> 撤销选择。递归树中每层表示一个决策位置，每条边表示一次选择。

经典模型：排列、组合、子集、八皇后、数独、单词搜索、迷宫路径、子集和、装载问题、连通块、岛屿数量。

八皇后冲突标记：列 col[y]、主对角线 dg[x-y+n]、副对角线 udg[x+y]。

4. BFS 最少步数

等权边图中，BFS 第一次到达某状态就是最少步数。

queue<pii> q;
memset(dist, -1, sizeof dist);
q.push({sx, sy});
dist[sx][sy] = 0;
while (!q.empty()) {
    pii t = q.front(); q.pop();
    int x = t.first, y = t.second;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (!inside(nx, ny) || g[nx][ny] == '#' || dist[nx][ny] != -1) continue;
        dist[nx][ny] = dist[x][y] + 1;  // 入队时标记
        q.push({nx, ny});
    }
}

输出路径：为每个状态记录前驱，终点反向追溯后翻转。

pre[nx][ny] = {x, y};  // BFS 首次到达时记录前驱

vector<pii> path;
for (pii p = {tx, ty}; p != make_pair(-1, -1); p = pre[p.first][p.second]) {
    path.push_back(p);  // 终点 -> 起点
}
reverse(path.begin(), path.end());  // 起点 -> 终点

起点前驱应先设为 {-1,-1}。只有终点确实被访问后才能还原；若 dist[tx][ty]==-1，说明无路可达。

5. 不同代价的搜索

边代价 方法 核心结构
全部相同 BFS queue
只有 0 和 1 0-1 BFS deque
非负权 Dijkstra / 优先队列搜索 小根堆

0-1 BFS：走 0 权边放队首，走 1 权边放队尾。

deque<int> q;
fill(dist + 1, dist + n + 1, INF);
dist[s] = 0;
q.push_front(s);
while (!q.empty()) {
    int u = q.front(); q.pop_front();
    for (pii e : g[u]) { // w 只能是 0 或 1
        int v = e.first, w = e.second;
        if (dist[v] > dist[u] + w) {
            dist[v] = dist[u] + w;
            if (w == 0) q.push_front(v);
            else q.push_back(v);
        }
    }
}

同一状态可能被再次松弛；需要更严谨地避免过时状态时，可记录队内状态或使用 Dijkstra 模板。

6. 双向 BFS 与剪枝

  • 起点、终点明确且状态空间大：可从两端扩展，优先扩展较小的一侧。
  • DFS 剪枝：越界、冲突、代价已超最优、剩余上界不足、同层重复。
  • 迭代加深：深度上限逐步增加，适合答案深度小但分支多的情况。

易错： BFS 出队才标记导致重复入队；DFS 连通块错误恢复 vis；状态信息不足；最小成本仍使用普通 BFS；忘记判界。

第二十二章 动态规划

1. DP 五问

问题 必须写清楚
状态 f[...] 的准确含义
转移 当前状态由哪些已算状态得到
初值 最小规模和不可达状态
顺序 转移来源必须先算好
答案 f[n]、max f[i]、f[n][m] 或其他位置

学习路径：普通 DFS 找到重复子问题 -> 记忆化保存结果 -> 按依赖顺序填写 DP 表。

int dfs(int x) {
    if (x == 0) return 0;
    if (mem[x] != -1) return mem[x];
    return mem[x] = min(dfs(x - 1), dfs(x - 2)) + 1;
}

2. 线性 DP

状态按序列位置推进，常见拆法：最后一步、最后一个元素、以 i 结尾、处理前 i 个。

最大连续子数组：

f[i]=max(a[i],f[i-1]+a[i]),    ans=maxi f[i]

数字三角形：

f[i][j]=a[i][j]+max(f[i-1][j-1],f[i-1][j])

路径计数：若只能从上或左来，f[i][j]=f[i-1][j]+f[i][j-1]，障碍位置为 0。

3. LIS

f[i] 表示以 a[i] 结尾的最长严格上升子序列长度：

for (int i = 1; i <= n; i++) {
    f[i] = 1;
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1);
    }
    ans = max(ans, f[i]);
}

复杂度 O(n^2)，答案是所有 f[i] 最大值，不一定是 f[n]。

二分优化：d[len] 表示长度为 len 的上升子序列中，最小可能结尾。

vector<int> d;
for (int x : a) {
    auto it = lower_bound(d.begin(), d.end(), x); // 严格上升
    if (it == d.end()) d.push_back(x);
    else *it = x;
}

最长不下降子序列把 lower_bound 改为 upper_bound。

4. LCS

f[i][j] 表示 a[1..i] 与 b[1..j] 的最长公共子序列长度：

f[i][j]={f[i-1][j-1]+1a[i]=b[j]max(f[i-1][j],f[i][j-1])a[i]≠ b[j]

复杂度 O(nm)；子序列不要求连续，子串要求连续。

二维 DP：

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a[i - 1] == b[j - 1]) f[i][j] = f[i - 1][j - 1] + 1;
        else f[i][j] = max(f[i - 1][j], f[i][j - 1]);
    }
}

从 f[n][m] 反向恢复一组 LCS：字符相等时选入并走左上；否则走向数值不减小的上方或左方。反向得到的字符最后要翻转。

string ans;
int i = n, j = m;
while (i > 0 && j > 0) {
    if (a[i - 1] == b[j - 1]) {
        ans += a[i - 1];
        i--, j--;
    } else if (f[i - 1][j] >= f[i][j - 1]) {
        i--;
    } else {
        j--;
    }
}
reverse(ans.begin(), ans.end());

只求长度时可压成一维。更新前的 dp[j] 是“上”，更新后的 dp[j-1] 是“左”，变量 pre 保存旧的“左上”。

vector<int> dp(m + 1, 0);
for (int i = 1; i <= n; i++) {
    int pre = 0;
    for (int j = 1; j <= m; j++) {
        int old = dp[j];
        if (a[i - 1] == b[j - 1]) dp[j] = pre + 1;
        else dp[j] = max(dp[j], dp[j - 1]);
        pre = old;
    }
}

一维后空间为 O(m)，可令较短字符串作为第二维；若要恢复具体序列，初学阶段保留二维表和回溯路径。

5. 01 背包

每件物品最多选一次。二维：

f[i][j]=max(f[i-1][j],f[i-1][j-wi]+vi)

一维必须倒序：

for (int i = 1; i <= n; i++)
    for (int j = m; j >= w[i]; j--)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

6. 完全、多重与混合背包

完全背包每件可选无限次，容量正序：

for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= m; j++)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

多重背包每件最多 c[i] 次：朴素枚举数量；常用二进制拆分为 1,2,4,... 个 01 物品。混合背包按每件物品类型选择相应循环方向。

7. 背包目标与初始化

题目问法 状态 / 初始化
容量内最大价值，不要求装满 dp[j]=0
恰好装满的最大价值 dp[0]=0，其余负无穷
恰好装满的最小代价 dp[0]=0，其余正无穷
恰好凑出容量的方案数 cnt[0]=1，其余 0，转移做加法

“重量”和“价值”可能换成时间/收益、花费/容量、分数/限制；先找谁是限制维度，谁是优化目标。

方案数中的组合与排列：按物品在外通常统计组合；容量在外、物品在内常会统计不同顺序，必须依据题意判断。

01 背包方案数：

vector<long long> cnt(m + 1);
cnt[0] = 1;
for (int i = 1; i <= n; i++)
    for (int j = m; j >= w[i]; j--)
        cnt[j] += cnt[j - w[i]];

完全背包方案数：把容量循环改为从 w[i] 到 m 正序。若答案取模，每次加法后 %mod。

多重背包二进制拆分：

vector<pii> item; // {拆分后的重量, 拆分后的价值}
for (int i = 1; i <= n; i++) {
    int c = num[i];
    for (int k = 1; k <= c; k <<= 1) {
        item.push_back({k * w[i], k * v[i]});
        c -= k;
    }
    if (c) item.push_back({c * w[i], c * v[i]});
}
for (pii t : item) {
    int w = t.first, v = t.second;
    for (int j = m; j >= w; j--)
        dp[j] = max(dp[j], dp[j - w] + v);
}

若 num[i]*w[i]>=m，从容量角度看可直接按完全背包处理该物品。

8. 区间 DP

区间 DP 适合“答案属于一段连续区间，而且大区间可以由更小区间得到”的问题。状态 f[l][r] 表示只处理闭区间 [l,r] 的答案。

先判断最后一次决策属于哪类：

类型 常见转移 典型问题
分割型 枚举 k，组合 [l,k] 与 [k+1,r] 石子合并、矩阵链乘
端点型 从 [l+1,r]、[l,r-1]、[l+1,r-1] 转移 回文、区间消除、取数博弈

计算顺序必须按区间长度从小到大，因为长度为 len 的区间依赖更短区间：

for (int len = 2; len <= n; len++) {
    for (int l = 1; l + len - 1 <= n; l++) {
        int r = l + len - 1;
        f[l][r] = INF;
        for (int k = l; k < r; k++) {
            f[l][r] = min(f[l][r], f[l][k] + f[k + 1][r] + cost(l, r));
        }
    }
}

石子合并中，合并 [l,r] 的最后一次操作一定把它分成 [l,k] 和 [k+1,r]。设前缀和为 s，最后合并代价是 s[r]-s[l-1]：

for (int i = 1; i <= n; i++) f[i][i] = 0;
for (int len = 2; len <= n; len++) {
    for (int l = 1; l + len - 1 <= n; l++) {
        int r = l + len - 1;
        f[l][r] = INF;
        for (int k = l; k < r; k++) {
            int now = f[l][k] + f[k + 1][r] + s[r] - s[l - 1];
            if (now < f[l][r]) {
                f[l][r] = now;
                cut[l][r] = k;  // 需要方案时记录最优分割点
            }
        }
    }
}

初始化： 单点区间通常不需要合并，故 f[i][i]=0；求最小值时其他状态设为 INF。端点型问题可能需要空区间，必须额外定义 l>r 的含义。

复杂度： 状态有 O(n^2) 个，每个状态枚举 O(n) 个分割点，总时间 O(n^3)、空间 O(n^2)。若合并代价频繁求区间和，应先做前缀和。

常见变化： 环形区间可把数组复制一遍，在长度不超过 n 的区间上做 DP；方案恢复从 cut[l][r] 递归进入两个子区间；括号匹配和回文问题常采用端点转移。

检查： 是否漏掉 k=l 或 k=r-1；长度循环是否覆盖到 n；最值初值是否正确；代价属于本次合并还是子区间；环形答案是否枚举所有起点。

6. 线段树基础

每个结点表示一段区间；pushup 用左右儿子合并当前答案。

struct node {
    int l, r;
    long long sum, tag;
} tr[N * 4];

void pushup(int u) {
    tr[u].sum = tr[u << 1].sum + tr[u << 1 | 1].sum;
}

void build(int u, int l, int r) {
    tr[u].l = l; tr[u].r = r;
    if (l == r) { tr[u].sum = a[l]; return; }
    int m = (l + r) >> 1;
    build(u << 1, l, m);
    build(u << 1 | 1, m + 1, r);
    pushup(u);
}

7. lazy tag 思想

区间被完全覆盖时，先更新当前结点并记录“欠给儿子的操作”；只有以后访问儿子时才 pushdown。

区间加：

void apply(int u, long long x) {
    tr[u].sum += x * (tr[u].r - tr[u].l + 1);
    tr[u].tag += x;
}

void pushdown(int u) {
    if (tr[u].tag == 0) return;
    apply(u << 1, tr[u].tag);
    apply(u << 1 | 1, tr[u].tag);
    tr[u].tag = 0;
}

完整区间加与区间和查询：

void modify(int u, int l, int r, long long x) {
    if (l <= tr[u].l && tr[u].r <= r) {
        apply(u, x);
        return;
    }
    pushdown(u);
    int m = (tr[u].l + tr[u].r) >> 1;
    if (l <= m) modify(u << 1, l, r, x);
    if (r > m) modify(u << 1 | 1, l, r, x);
    pushup(u);
}

long long query(int u, int l, int r) {
    if (l <= tr[u].l && tr[u].r <= r) return tr[u].sum;
    pushdown(u);
    int m = (tr[u].l + tr[u].r) >> 1;
    long long ans = 0;
    if (l <= m) ans += query(u << 1, l, r);
    if (r > m) ans += query(u << 1 | 1, l, r);
    return ans;
}

调用时查询或修改区间必须与建树下标体系一致，例如全部使用 1..n。

标记合成：

操作组合 处理
加后再加 加法标记累加
乘后再乘 乘法标记相乘
乘加仿射 新变换复合旧变换，注意顺序
赋值后再加 赋值标记保留，再调整赋值值
加后再赋值 旧加标记被新赋值覆盖

同时维护“区间赋值”和“区间加”时，赋值优先覆盖旧操作；加法则叠加到当前赋值结果上：

void apply_set(int u, long long x) {
    tr[u].sum = x * (tr[u].r - tr[u].l + 1);
    tr[u].set = x;
    tr[u].has_set = true;
    tr[u].add = 0;      // 新赋值覆盖此前尚未下传的加法
}

void apply_add(int u, long long x) {
    tr[u].sum += x * (tr[u].r - tr[u].l + 1);
    if (tr[u].has_set) tr[u].set += x;
    else tr[u].add += x;
}

has_set 不能用 set!=0 代替，因为“赋值为 0”也是有效操作。pushdown 时必须先下传赋值，再下传加法，顺序与操作合成关系一致。

lazy 检查：完全覆盖直接更新；下探前 pushdown；下探后 pushup；传播后清空父标记；多标记明确优先级和合成顺序。

10. LCA 基础模板

void dfs(int u, int fa) {
    dep[u] = dep[fa] + 1;
    up[u][0] = fa;
    for (int k = 1; k < LOG; k++)
        up[u][k] = up[up[u][k - 1]][k - 1];
    for (pii e : g[u]) {
        int v = e.first, w = e.second;
        if (v == fa) continue;
        dist[v] = dist[u] + w;
        dfs(v, u);
    }
}

int lca(int a, int b) {
    if (dep[a] < dep[b]) swap(a, b);
    for (int k = LOG - 1; k >= 0; k--)
        if (dep[up[a][k]] >= dep[b]) a = up[a][k];
    if (a == b) return a;
    for (int k = LOG - 1; k >= 0; k--) {
        if (up[a][k] != up[b][k]) {
            a = up[a][k]; b = up[b][k];
        }
    }
    return up[a][0];
}

12. 树上差分

批量路径修改，最后一次 DFS 自底向上累加。

点差分，路径 u-v 每个点加 x：

d[u] += x;
d[v] += x;
d[lca(u, v)] -= x;
d[parent[lca(u, v)]] -= x;

边差分，路径上的每条边加 x：

d[v] += x;

4. Z 函数

z[i] 表示 s[i..] 与整个字符串前缀的最长公共前缀长度。维护当前最右匹配区间 [l,r]，区间内先复用已知值，再暴力扩展；总复杂度 O(n)。

用途：模式匹配、前缀出现次数、字符串周期、每个后缀与前缀的 LCP。

vector<int> z_function(const string &s) {
    int n = s.size();
    vector<int> z(n);
    for (int i = 1, l = 0, r = 0; i < n; i++) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] - 1 > r) {
            l = i;
            r = i + z[i] - 1;
        }
    }
    return z;
}

模式串 p 匹配正文 s 可构造 p + '#' + s，在对应位置检查 z[i]>=p.size()；分隔符不能出现在原字符串中。

5. 中心扩展与 Manacher

中心扩展枚举 2n-1 个中心，分别向两边扩展，最坏 O(n^2)。

Manacher 把字符串插入分隔符统一奇偶回文，p[i] 记录中心 i 的回文半径；维护当前最右回文区间中心 c 和右端 r：区间内利用镜像初始化，再继续扩展。总复杂度 O(n)。

原串奇回文与偶回文也可使用两组半径数组 d1/d2 表示，避免字符改造。

中心扩展模板：

int expand(const string &s, int l, int r) {
    while (l >= 0 && r < s.size() && s[l] == s[r]) {
        l--; r++;
    }
    return r - l - 1;
}

int longest_pal(const string &s) {
    int ans = 0;
    for (int i = 0; i < s.size(); i++) {
        ans = max(ans, expand(s, i, i));     // 奇数长度
        ans = max(ans, expand(s, i, i + 1)); // 偶数长度
    }
    return ans;
}

    int c = 0, r = 0, ans = 0;
    for (int i = 1; i + 1 < t.size(); i++) {
        if (i < r) p[i] = min(r - i, p[2 * c - i]);
        while (t[i + p[i] + 1] == t[i - p[i] - 1]) p[i]++;
        if (i + p[i] > r) c = i, r = i + p[i];
        ans = max(ans, p[i]);
    }
    return ans; // 原串最长回文子串长度
}

哨兵字符 ^、#、$ 必须保证不出现在输入字符集中。

6. Trie

int son[N][26], cnt[N], idx;

void insert(const string &s) {
    int p = 0;
    for (char c : s) {
        int u = c - 'a';
        if (!son[p][u]) son[p][u] = ++idx;
        p = son[p][u];
    }
    cnt[p]++;
}

int query(const string &s) {
    int p = 0;
    for (char c : s) {
        int u = c - 'a';
        if (!son[p][u]) return 0;
        p = son[p][u];
    }
    return cnt[p];
}

cnt 表示完整单词结束次数；若需前缀统计，沿路维护 pass。

8. 后缀数组

  • sa[i]：排名第 i 的后缀起点。
  • rk[i]：起点 i 的后缀排名。
  • height[i]：sa[i] 与 sa[i-1] 的最长公共前缀。

倍增法每轮按长度 2^k 的两段排名排序并重新编号，约 O(n log^2 n)，计数排序优化可到 O(n log n)。

用途：后缀排序、最长重复子串、最长公共子串、不同子串数量。不同子串数：

n(n+1)2-∑ height[i]

9. 后缀自动机

每个状态表示一组 endpos 相同的子串，核心字段：len、link、字符转移、出现次数。每加入一个字符创建 cur，必要时创建克隆状态 clone 修正转移和后缀链接。

性质：状态 v 代表的不同子串长度范围为 (len[link[v]], len[v]]，不同子串总数：

∑v≠ root(len[v]-len[link[v]])

用途：不同子串数、最长公共子串、子串出现次数、按字典序查询子串。属于高阶内容，先掌握 KMP、Trie、哈希和 Manacher。

易错： KMP 成功后未回退继续匹配；哈希未预处理幂；Trie 的结束次数与经过次数混淆；AC 自动机漏 fail 链匹配；Manacher 半径与原串长度换算错误。
