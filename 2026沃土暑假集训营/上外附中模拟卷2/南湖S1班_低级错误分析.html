four🔴 1个错误
O(n³) 超时 L101-L105
for(int i=1;i<=n;++i) for(int j=1;j<=n;++j) for(int k=1;k<j;++k) if(a[i]>a[k]) ++l[i][j]; // 预处理 O(n³)
错误原因：答案公式 l[k][j]*r[j][k] 正确，但 l/r 数组用三层循环预处理 O(n³)，n=2000 时超时（约 8e9）。
订正：用前缀和 O(n²) 维护 l/r。
string🔴 1个错误
算法偏离 L129-L138
ans+=x.second/2-1; ans+=cnt; if(res!=0) ans=ans-res/2*2+1+res*(res-1)/2;
错误原因：拼凑的公式对奇数频次字符算错，如 "aaa" 输出 4（应为 6）、"aaabb" 输出 7（应为 9）。
订正：Σ cnt[c]*(cnt[c]+1)/2。

订正：dfs 求解。

函数无返回 L450-L456
bool ff (char c) { if (isdigit (c)) return 1; else if (字母) return 0; } // 非字母数字时无 return，未定义行为
错误原因：ff 对非字母数字字符（如 '.'）没有 return，返回值未定义，导致根目录判断不可靠。

file🔴 1个错误
substr 越界 L776
t.substr(t.end()-4-t.begin(), t.end()-t.begin()) // 第二参数长度=t.size()，越界
错误原因：substr 第二个参数是长度，却传了 t.size()，实际应传 4；且 check2/check3 中 !、&&、|| 优先级混乱。
订正：改为 t.substr(t.size()-4) == ".cpp"，并加括号明确优先级。
four🔴 1个错误
算法偏离 L842-L864
sort(v.begin(),v.end()); ll cnt = y * (x - y - 1); // 按排序后 id 乱算
错误原因：排序后按 id 相减拼凑计数，与四元组 i<j<k<l 的约束毫无关系。
订正：枚举 j,k 用前后缀计数。
string🔴 2个错误
substr 越界 L919
s.substr(v[i].first, v[i].second) // 第二参数是下标，非长度
错误原因：substr 第二参数误用为结束下标，应为 v[i].second - v[i].first + 1，导致取串错误。
订正：修正长度参数。
调试残留 L903, L918
cerr<<s.size()<<' '<<s<<el; cerr<<v[i].first<<' '<<v[i].second<<...<<el; // 大量 cerr
错误原因：大量 cerr 调试输出，且 next_permutation 前未 sort，枚举不完整（复杂度还极高）。
订正：删除 cerr，直接用公式求解。
